## Protocol stress tests and scope

`critic_protocol.py` records eight explicit fault cases: old-session high epochs, concurrent stale predecessors, same epoch with different payload, cancellation delivered after execution, cancellation after physical displacement, unbounded clock offset, receipt acknowledgement without actuator delivery, and safe rejection incorrectly counted as completion. Session identity and an atomic expected-predecessor check handle selected ordering races, but they neither establish truthful authority nor complete a motion task.

A cancellation cannot retroactively undo physical movement. Even an authenticated, correctly ordered cancellation needs a declared effective time, allowed transition, and verified stop/replacement policy. If it is not delivered before a pending event executes, the receiver cannot behave differently from the world with no cancellation. Fixed deadlines require bounds on delivery, admission, queueing, and clock correspondence; a locally valid timestamp can be expired in true time under unknown offset. Rejecting an impossible request can preserve safety while failing the requested task.

Independent replay in `critic_replay.py` uses producer transitions but separate monitors, not its invariant-check function. It checks9,331 traces and44,790 transitions over the declared six-packet alphabet. The original producer model was byte-snapshotted as `critic_protocol_snapshot.py` with provenance hash before refinement. Boundary probes show that original `complete` packets bypass session/version checks and can clear a later task; unknown `cancel` kinds fall through as revisions. The producer explicitly assumes completion is a trusted full-reference-tail oracle, so this is an abstraction/API boundary, not a discovered deployed controller bug. Domain is refining the oracle name and rejecting unknown kinds. A real task-bound completion notice remains insufficient unless its full-tail predicate is actually justified.

`critic_replay.py` also independently checks the inventor's three-goal encoding counts, all radius-one Hamming decodes, and absence of a three-codeword distance3 code of length below5. The binary counts are0; the three-symbol counts are6. The optional bit-error coding model is separate from original noisy measurements and does not make task content truthful. Three corruptions of code distance, exact error, and encoding count are rejected. The finite protocol experiment includes no bounded-memory implementation or universal induction over arbitrary trace length.
