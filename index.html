1. End-to-End Walkthrough: From Lean 4 Theorem to <100 ns C99 Kernel

When a legged robot or mobile platform brakes near an obstacle, it can fail in two ways: its feet can slip outside the friction cone (μ), or its center of mass (height hG, stance half-width W) can pitch over the front support edge. Online QP-CBF controllers solve a quadratic program at every tick to stay safe, which can fail to converge or miss hard real-time deadlines. Here is how ctrl replaces the online solver with a proved closed-form filter:

Step 1 · Lean 4 Proof Over ℝ (LorentzConeCBF.lean)

We prove in Lean 4 (0 sorry) that setting the maximum deceleration to a_max = min(μ, W/h_G) * g and distributing ground forces across the 4 feet via a bilinear Zero-Moment-Point (ZMP) + proportional shear law satisfies: 

theorem quad_contact_zero_angular_momentum (p : QuadParams) (ax ay : ℝ) :
    netEulerTorque p (quadContactForce p ax ay) = 0

theorem quad_contact_in_lorentz_cone (p : QuadParams) (ax ay : ℝ)
    (h_accel : ax^2 + ay^2 ≤ (safeDecelMax p)^2) :
    ∀ corner, inLorentzCone p.mu (quadContactForce p ax ay corner)
Step 2 · Zero-Heap C99 / PLC Kernel (codegen.py)

Because the safe acceleration set and stopping-distance barrier h(r, v) = n · (r_lim − r) − v_n^2 / (2 a_brake) have an exact convex-interpolation solution between the nominal command u_nom and backup braking pi_b, the deployed C99 filter has no loops, no heap allocation, and no solver failure states: 

void ctrl_lorentz_cbf_filter_3d(
    const double a[3], double b,
    const double u_nom[3], const double pi_b[3],
    double *lam_out, double u_safe[3]) {
  double num = b - ctrl_dot3(a, u_nom);
  double den = ctrl_dot3(a, pi_b) - ctrl_dot3(a, u_nom);
  double lam = (num <= 0.0) ? 0.0 : ((den > 0.0 && num < den) ? (num / den) : 1.0);
  *lam_out = lam;
  for (int i = 0; i < 3; ++i) u_safe[i] = (1.0 - lam) * u_nom[i] + lam * pi_b[i];
}
Why the C99 kernel and the Lean theorem match (and where the boundary lies): Each theorem-backed function in src/ctrl/robotics/ runs in two modes: exact rational arithmetic (fractions.Fraction) on rational test grids to verify exact algebraic equivalence with the Lean polynomial/rational formulas over ℚ ⊂ ℝ, and IEEE-754 float64 for runtime execution. The C99 shared library is compiled with clang -std=c99 -O3 -Werror and checked via ctypes against the Python reference to 8.88 × 10−16 (1 ULP).

3. Practical Application Combinations

The primary value of having control, estimation, kinematics, and trajectory modules in one repository is that they compose cleanly into end-to-end robotics pipelines:

Application 1 · Industrial 6-DOF Manipulators

Septic Trajectory Shaping + Slotine–Li Passivity + Sontag CLF / H∞

Modules: RobotEnergySmoothness.lean + ManipulatorTracking.lean + BacksteppingCLF.lean + BoundedRealHInf.lean.
Why they fit together: Rest-to-rest 7th-order septic profiles (η = −11) smooth out peak acceleration at the endpoints to reduce motor winding heat, while Slotine–Li passivity tracks the reference using skew-symmetry of Ṁ − 2C (avoiding noisy M(q)−1 inversions), and Sontag's universal CLF + H∞ damping add a closed-form nonlinear disturbance rejection term.

Application 2 · Legged & Wheeled Mobile Robots

3D Lorentz-Cone CBF + Bilinear 4-Foot ZMP Allocator + Real-Time Simplex

Modules: LorentzConeCBF.lean + CentroidalDecelerationLimit.lean + SE3Kinematics.lean + RoboLean/RealTime.lean + RoboLean/Reliability.lean.
Why they fit together: Combines worst-case response-time schedulability and Simplex architecture switching with an analytical 3D stopping-distance barrier and 4-foot wrench allocator. Gives legged/wheeled robots a deterministic reflex shield that runs on microcontrollers or PLCs where OSQP/ECOS cannot run reliably.

Application 3 · Eye-in-Hand Visual Inspection & Docking

4-Point Homography Rigidity + Faugeras Chirality Filter + Log-Depth SE(3) Servoing

Modules: HomographyUniqueness.lean + HomographyDecomposition.lean + VisualServoingInvariant.lean + KalmanOptimality.lean.
Why they fit together: Extracts planar pose from 4 feature correspondences, eliminates the unphysical Faugeras reflection branches via chirality (n · X > 0), filters pose noise with a Bucy–Joseph covariance update, and decouples optical-axis roll from depth control so large camera rotations never trigger backwards camera retreat.

Application 4 · Minimal-Sensor Embedded Estimation & Control

Detectable DARE + Steady-State Kalman / Information Filter + Peter–Paul ISS

Modules: DAREDetectable.lean + SteadyStateKalman.lean + InformationFilter.lean + ISS.lean.
Why they fit together: Certifies LQR and Kalman convergence when only a low-dimensional output y = Cx is measured (Q = C⊤C ⪰ 0 positive semidefinite rather than positive definite), pairs it with the Sherman–Morrison–Woodbury information update for multi-sensor fusion, and computes an explicit Peter–Paul ISS invariant tube under bounded process noise.

2. Closing the Last Off-Diagonal Cross-Term in n=6 Byers–Nash

For the continuous Lyapunov operator ℒA(X) = A⊤X + XA, the Byers–Nash question asks whether the minimum singular value on skew matrices k(A) is always ≤ the minimum singular value on symmetric matrices s(A). We proved orthogonal decoupling on 𝕊n ⊕ 𝕂n, unconditional exclusion for rank ≤ 4, and a 15D Parseval decomposition of 𝕂6, plus exact rational LDL⊤ ≻ 0 certificates on a 10-pair non-Common-T grid. Bounding the remaining 3D commuting off-diagonal cross-term analytically is in work.
