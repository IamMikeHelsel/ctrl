Study 02 · exact finite arithmetic + a formal inequality

An assignment can carry its own cost gap.

Check conservation and dual feasibility before trusting an allocation. The prototype reports an honest interval for the optimal cost, including when the submitted assignment is poor.

PrincipleResultsLimitsReproduce

Separate the search from the check

A transport plan sends nonnegative mass from source bins to target bins. Row and column sums must match the specified marginals. A candidate plan supplies an upper bound on the best possible cost. Feasible dual potentials supply a lower bound.

Primal obligations

p[i,j] ≥ 0
Σj p[i,j] = source_mass[i]
Σi p[i,j] = target_mass[j]
U = Σij p[i,j] cost[i,j]

Costs can be negative. Total mass must be positive and balanced; it need not equal one.

Dual obligations

u[i] + v[j] ≤ cost[i,j]   for every pair
L = Σi source_mass[i] u[i]
  + Σj target_mass[j] v[j]
L ≤ optimal cost ≤ U

Check every pair, including edges a partitioned search did not use. Otherwise a restricted problem can silently replace the intended one.

Motivated by partitioned transport for multi-agent distribution matching and the search/check separation in CP-Cert for pose registration. Weak duality is standard mathematics. This prototype reproduces neither paper's full method nor its performance results.

Small results with inspectable witnesses

Synthetic source coordinates [0, 1, 10, 11], target coordinates [1, 2, 11, 12], squared distance costs and equal masses. Coordinates are unitless. Every example has an independently enumerated optimal cost of 1.

Executable checks

Independent tiny-instance oracle

Across 24 seeded integer-cost instances of size 2–5, all 912 candidate intervals enclosed the enumerated optimum. The witness generator rejected 884 strictly suboptimal assignments as candidates for a tight dual.

Six corrupted or malformed study inputs were rejected. A rectangular mass-splitting example also produced an exact [¼, ¼] interval. Eighteen focused tests pass.

Formal model

Finite rational weak duality

A separate Lean file proves the finite transport weak-duality inequality and a candidate-gap implication. Both compile with only propext, Classical.choice and Quot.sound.

The second implication assumes a candidate-cost upper bound; candidate feasibility is a separate obligation. Individual Python witnesses have not been replayed in Lean.

Where it could be useful—and what is missing

A future allocation component could attach a checked gap to a fast partitioned result, then decide whether a global solve is worth the cost. The useful measurements would be gap quality, checker time, witness size and total computation saved under identical inputs.

This pass has not measured a speedup. It establishes no motion dynamics, collision avoidance, deadline guarantee, sensor robustness or floating-point refinement. Tiny uniform assignment enumeration does not validate every transport problem. A low assignment cost is not a navigation safety result.

Next falsifier: export exact witnesses from realistic costs and partitions, replay them in Lean, and compare the checking overhead with solver time saved. If the gaps are too wide or checking erases the saving, defer the integration.
