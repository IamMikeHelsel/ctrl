Where the ideas come from

Tao’s work informs the methods: finite countermodels, additive structure, and visible proof dependencies. OpenAI’s math repository supplies two precisely scoped starting points: a tropical counterexample and a unit-job scheduling specification. The control applications and small experiments here are our adaptations.

Run it, change it, embed it

The source lives in tools/math_explainers and experiments/math_explainers. The result artifact records exact values, source links, checks, and a content hash.

uv run experiments/math_explainers/run.py
uv run python -m pytest -q tests/test_math_explainers.py
uv run python tools/math_explainers/render.py
npm ci --prefix tools/math_explainers
npm run build --prefix tools/math_explainers

Each player is a standalone HTML download with media and fonts included. For a website or Google Sites, embed its hosted URL with ?embed=1. Google Slides can use the exported PNGs or an MP4 uploaded to Drive; Docs can use PNGs and a link to the interactive page. Interactive scripts do not run inside a Docs or Slides page.
