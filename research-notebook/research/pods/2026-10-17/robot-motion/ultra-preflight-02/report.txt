MATHEMATICAL ASSESSMENT

No counterexample was found to the stated finite-knot equivalence. It is true
for every finite event list, h>0 and J>=0. Chronological input is needed for the
scheduler interpretation, not for this algebraic equivalence.

For d=0,1,2,3, define
  F_d(z) = sum_{m=0}^4 (-1)^m C(4,m) (z-m)_+^(4-d)/(4-d)!.
The required derivative chain is F_0'=F_1, F_1'=F_2, F_2'=F_3 at EVERY real z.
It follows by proving the positive-part power derivative for powers 4,3,2.
At a joining point the derivative is zero for these powers; away from it the
function is locally either zero or an ordinary polynomial. Each F_d is
continuous. Thus F_0 is C3, including all five joins. Do not prove the derivative
only away from knots and call that C3.

F_3(z)=sum (-1)^m C(4,m)(z-m)_+ gives exactly the six K branches in the contract.
For z>=4, expand all positive parts: the coefficients give F_0=1 and F_1=F_2=
F_3=0. For z<=0 they all vanish. Both tail identities must be proved from F,
not built into an unrelated piecewise reference and assumed equivalent.

The complete-knot proof need not assume a partition. Define E from the actual
event roots and c. For any t>=c, if t is in E, use the guard. Otherwise take the
greatest member L of E below t; it exists since c is in E. If there is a later
member, take the least such member R. There is no event root inside (L,R): any
such root is >=c and therefore belongs to E, a contradiction. Each positive-part
term in F_3 is affine throughout [L,R], so the entire jerk is the linear
interpolation of its endpoint values. The absolute value is bounded by the larger
endpoint absolute value. If there is no later member, all event tail times are
at or before t, so jerk is zero. A tail time below c has already expired. This
also covers duplicate roots, c inside a cell, empty input, and the infinite tail.

Use that positive-part argument to avoid a combinatorial split across six K
branches for every event. Derive the actual K branches separately as simple
algebraic identities. This is a feasible package with finite-set order lemmas,
calculus, exact rational casts, and a short state induction. The proof effort is
moderate; it is more than a renamed finite predicate over reals.

COUNTEREXAMPLES THAT THE IMPLEMENTATION MUST KEEP

1. Omitting c is unsound. With h=1, event (0,1), c=7/2, J=1/4, the only future
   event root is 4 and its jerk is zero. At c, jerk is 1/2 and fails the limit.
2. Checking just the start and tail is unsound. The same step has zero jerk at
   0 and 4, but jerk -2 at time 2. This also rejects the false unit constant 1.
3. Dropping old ACTIVE history is unsound. At c=1, event (0,1) still has jerk -2
   at time 2. Event time before c does not mean its support has expired.
4. Erasing future commitments is unsound. With h=1, J=1, c=0, events (0,1) and
   (1/4,-1) have exact future peak 3/4. Removing the second event leaves peak 2.
   Acceptance based on cancellation obliges execution of that committed event.
5. Duplicate opposite events can cancel exactly. Rejecting them solely because
   of large total variation is a different, conservative guard. The main theorem
   must retain signed sums. The fixed scheduler coalesces alternatives BEFORE
   admission; this is different from deleting an already committed event.

REQUIRED CONTRACT REVISIONS

A. Separate admission time c from execution time tau. State 0<=c<=tau, with
   nondecreasing admission times. The simplest first scheduler sets c=tau at
   the commit tick and has no future queue. If future committed input is allowed,
   store every such event in the candidate guard, append only after the already
   committed chronological target, and preserve it. Delta is relative to that
   final committed target. A new event with tau>=c has zero contribution and
   derivatives through c, so the required prefix proof still holds.

B. Batch all packets ready by a commit tick before admission. Sequence values
   must identify a unique payload, or conflicting duplicate sequences need an
   explicit reject/tie rule. The frozen cases have no such conflict. Advancing
   the sequence watermark on rejection is correct for this declared policy, but
   it can suppress a later-arriving feasible older goal. State that progress is
   not guaranteed. Do not reset history on rejection, stale arrival, or no-change.

C. Make an executable Lean Rat Boolean function the authoritative checker.
   It can check c plus a list of filtered roots; sorting and deduplication are
   optional for correctness. Prove cast equality of jerk evaluations, preservation
   of root membership and order, and soundness against the actual real reference.
   Prefer the iff form if inexpensive. Evaluate or kernel-prove the frozen finite
   fixtures with this same function. Python agreement alone does not certify
   Python execution. If Python remains the runtime authority, its implementation
   correspondence is an additional unfinished obligation. The supplied Python
   functions expect rational inputs but do not enforce their types themselves.

D. Prove finite admission induction. The initial empty history has zero jerk.
   Acceptance gives the future bound; prefix preservation gives the past bound.
   Rejection retains the old bounded history. Later steps cannot rewrite an
   earlier executed prefix. The final reference target is g0+sum(delta); prove
   that this equals the scheduler's final committed target by telescoping. The
   rest tail begins at the greatest accepted execution time plus 4h. For an
   empty history the reference is already at rest. Include every queued accepted
   event when identifying the final event.

E. Label settling as 'enter and remain through the fixed observation horizon'.
   Samples over a finite horizon do not prove no later exit. An infinite-time
   claim needs a separate tail argument. Keep the frozen deadlines and horizons.

TRACKING COMPOSITION

I checked the actual ScaledTracking.lean statements. tracking_cube_scaled needs
reference continuity and the derivative chain on the whole open horizon, the
reference jerk bound on the closed horizon, the classical plant trajectory,
rate/disturbance bounds, initial transformed-cube membership, and the budget.
The proposed C3 reference can discharge the reference premises directly. The
controller formula matches. No command filter or mismatch bound is needed.

The formal conclusion is conditional on the physical trajectory hypotheses.
It does not prove model identification, solution existence, sampled control,
or state estimation. A C3 reference is compatible with continuous plant states.
Continuous physical jerk additionally needs continuous rate r and disturbance w;
magnitude bounds alone are insufficient. Preserve actual state across every
event. The initial rest reference and actual rest state give zero initial error
for the fixed cases; they do not cover an arbitrary moving initial arm.

At final reference rest, the cube gives position error <=R, speed <=8 sigma R,
and acceleration <=64 sigma^2 R. With the proposed numbers these latter bounds
are .016 m/s and 1.28 m/s^2, much weaker than the endpoint tests .001 and .02.
Do not promote the internal tube into all endpoint tests or a true-goal tube.
The actual-jerk bound 144.975 m/s^3 is consistent with the supplied algebra and
is distinct from the reference limit 7.5 m/s^3.

COMPARISON ACCEPTANCE

The frozen 3 x 4 x 3 x 2 = 72 cases are a fair bounded diagnostic when interpreted
as a speed/smoothness tradeoff under common deadlines. All methods receive the
same readiness/coalescing/stale trace; all primary FIR proposals happen to pass.
The filter's 800 ms support delay remains part of its result. Ruckig uses maximum
limits while the 20 mm filter step uses less. Lower jerk energy alone can reflect
slower motion. Do not conclude general superiority, and do not tune the current
gate. A duration-matched comparison would be a separately frozen later gate.

The raw-target method has position jumps, so it is a diagnostic baseline outside
the smooth-reference theorem. Its reference derivatives are not finite physical
impulses. With retained actual state its command jump is 8 sigma^2 Delta q.
The Ruckig command jump is 5 Delta jerk/(48 sigma) when its position, velocity and
acceleration match. Use exported left/right states at replans; account for any
floating-point mismatch separately. Compute actual jerk from the plant equation.

The augmented matrix-exponential plan is appropriate for the fixed polynomial
reference and constant r,w. Include zero, readiness/commit boundaries, all phase
switches, the requested deadline, final tail and full horizon. Keep actual state
continuous at all of them. The independent high-precision run must reconstruct
its schedule and states, not reuse the primary segment starts. Refinement checks
must cover sampled extrema, energy and total variation. TV includes jumps.

The existing simulation can give numerical support at samples, and one failing
sample is a real counterexample to the claimed tolerance in that model. Passing
samples do not enclose all between-sample extrema. Record signed endpoint error,
velocity and acceleration separately. Keep internal x-q and external x-g_true
separate. No full-arm, learned-policy, timing-deadline, or hardware claim follows.
