Independent methodological challenge — Moving-goal08

The initial return-to-zero design could reward a controller that never moved.
Before any run, the assessor added x(.50)-x(0)>=1mm. All methods receive the same
authoritative requests. A rejected request counts as failure. No FIR acceptance
trace censors the other methods. Lower activity after rejection cannot win.

A deadline before delivery is a failed causal service promise. It is not a
universal physical impossibility theorem: a system could coincidentally be at
the final target. This distinction is explicit in the frozen protocol. A/B have
identical inputs and must have identical physical traces; only scoring differs.

All methods retain the same60ms immutable buffer in caseC. Native plans carry
the state at execution, not at admission. FIR increments use the previous
accepted target, not current reference or physical position. Rejected D records
a requested execution time without claiming an event executed there.

A jerk-only guard cannot claim V/A/J conformity. Before plant runs, the protocol
adopted a separately declared common numerical allowance of1e-10 in each SI unit.
This is distinct from the native reconstruction tolerances and is not an exact
reference limit theorem. Signed excess and exact FIR evidence remain visible.
Independent exact rational reconstruction confirms A/B acceleration21/32m/s^2
with accepted jerk25/4m/s^3; C acceleration1/2 and jerk5; D candidate jerk45/4
is rejected and the prior accepted20mm event remains.

Progress from each method's own state at revision is useful but the remaining
distances differ. This is not an equal-distance effort ranking. The energy-like
metric is the integral of jerk squared, in m^2/s^5, not electrical energy.

The numerical gate checks one scalar plant, fixed schedules, three rates, two
constant disturbances and two sample grids. All-time position task proof08 has
a different, completed-tail hypothesis. It does not certify these reversals.
