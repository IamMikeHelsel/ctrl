C3 REPLAY

The complete local closure has four modules. verification.json records exact
source and executable hashes, commands, external package pins, axiom closures,
exit codes and log hashes. Fresh builds exclude cached local project proofs.
Each module receives a separate leanchecker replay. Every declared theorem
closure is checked against only propext, Classical.choice and Quot.sound.

The verifier requires an empty fresh-replay directory and does not overwrite
frozen evidence. For independent replay, copy the four sources into a new
reviewer-owned directory. Use the recorded pinned binaries and external
package paths, replacing only scratch input/output/root paths. Build in order:
DigitalHold, AdaptiveAdmission, AdaptiveWitness, AdmissionInterface. Recreate
the audit there and replay the seven negative controls in separate scratch.
Do not rerun the verifier over this frozen directory.

Seven negative controls
  WiderVelocityGuard: change .02 to .03; the unchanged certificate fails.
  WiderAccelerationGuard: change 1.25 to 1.4; it also fails. Exact sensor-box
    states in AdmissionInterface show the claimed initial cube is false for
    these widened guards. No later physical failure is claimed.
  FiveMillisecondAge: change age .001 to .005; history/expiry proofs fail.
  FiveMillisecondStartup: change startup .0005 to .005; startup proof fails.
    These mutations reject the submitted route, not every possible controller.
  FalseFixedCenterShift: assert the chosen center stays fixed after translating
    measured position by one metre. Exact arithmetic rejects the assertion.
  FalseClearance15: assert the nominal new upper tube is <=.15. It is .1564625.
  FalseRenewedStamp: assert a stamp-zero read at global time .002 has age<=.001.
    This rejects an age reset. The main source also proves the first-cell
    no-extra-time theorem with the actual schedule.

Missing files, unknown identifiers and missing modules are not accepted as
rejection evidence. Attempts and harmless warnings remain recorded.
The local admission screen is separate from Lean evidence. It does not run a
new dynamics simulation. No remote job, paid service or Git command was used.
