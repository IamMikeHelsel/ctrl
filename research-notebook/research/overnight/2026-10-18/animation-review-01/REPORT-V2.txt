Independent data check
check_data.py is a separate standard-library program. It imports no animation,
builder, optimizer or physical-replay code. It directly reads the four stored
compressed CSV traces at response100/s, disturbance0, generous deadline1.70s,
and output spacing0.5ms. These traces were already independently replayed using
80-digit arithmetic in critic-03 and smooth-review-01. This review does not
repeat that plant integration. It binds the movie to those reviewed traces and
independently recomputes its sampled metrics with60-digit decimal arithmetic.

All20,178 source rows map exactly to the animation's times and actual positions.
The check uses each stored rational timestamp. Position conversion to millimeters
matches exactly at the binary-float display boundary. Every repeated event time
has identical x/v/a on both sides, so linear interpolation has no ambiguous
physical jump. All four physical prefixes match through the left side of0.52s.
The source uses linear interpolation only for display, with no spatial retiming
or physical state reset. Animation time is a separate, slower display clock.

The suffix is[0.52,2.50]s. Trapezoidal jerk-squared integration preserves the
saved left/right event order. Equal-time event sides add zero area. The peak
is the largest absolute saved actual jerk. Extra forward travel is
max(0,max(x(t))-x(0.52)), using saved samples in that interval.
