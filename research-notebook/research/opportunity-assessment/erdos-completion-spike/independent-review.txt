that 0<=p(v)<=1, sum_v p(v)=n/2 EXACTLY, and

BRANCHES, DENOMINATORS, AND MOMENTS
Case1 selects exactly m neighbors within D. Triangle-freeness makes them
independent; disjointness from B gives exactly |B|+m=t vertices, not merely
at most t. Their indicator is consequently an exact fractional half.
Case2 has B nonempty, so b=|B|>0. For each v in B,
  r_v=|N(v) intersect D| < m <= |D|=d,
so d-r_v>0. Thus w_v=(m-r_v)/(d-r_v) is a legitimate rational weight in[0,1],
including w_v=1 when m=d. The profile is 1_B+1_E+w_v*1_(D\E), with disjoint
supports as needed, and has exactly |B|+r_v+w_v(d-r_v)=|B|+m=t mass.
The first moment sum_B r_v=sum_D deg_B is an actual incidence equality.
The cross-cost sum_B cross(B,E_v)=sum_D deg_B^2 has the correct factor2 for
the symmetric bilinear convention. The degree interval gives the upper
second-moment bound; the variance identity gives sum_B r_v^2>=b*R^2 where
R=(sum_B r_v)/b. Since the quadratic coefficient is negative, its use has the
correct inequality direction. Finite nonempty averaging selects a real
profile witness; the conclusion does not merely assert a scalar average.
Mantel's contribution on D\E is derived from mathlib's triangle-free Turan
bound on the actual induced graph, not a new unproved graph hypothesis.

3. From eventual input to all orders
For nonempty G, the eventual-BCL transport uses k=N+1 independent clones of
each vertex; then |V|k>=N and k>0. Triangle-freeness is preserved. The imported
internal-cut transport is a genuine theorem, not an equality assumed for
optimal cuts: average the blow-up cut indicator in each clone class, then
round coordinates using the affine internal-cut objective, without increasing
cost. This gives the normalized cut bound back on G, with no additive error
or asymptotic limit step.

For the fractional half, applying the even-order construction to G's two-fold
blow-up gives order2n. Averaging independent clone pairs yields weights in[0,1]
and exact original mass n/2. Cost scales exactly by1/4 while graph order squared
also scales by4; normalized edge cost is preserved. This handles odd n without
mistaking floor(n/2) for the fractional mass n/2.

The final rounding theorem transfers mass between two fractional coordinates,
uses the nonpositive quadratic coefficient along that direction to avoid
increasing cost, and reduces the number of fractional coordinates by finite
induction. It leaves at most one. Keeping coordinates equal to1 and discarding
the possible fractional remainder gives exactly floor(n/2) vertices; deleting
nonnegative weight cannot increase edge cost. The argument is for arbitrary
finite simple graphs, so no unmentioned graph class assumption enters here.

The empty graph is handled by explicit empty/zero witnesses before any use of
