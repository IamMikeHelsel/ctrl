Why releasing the command is insufficient
For a constant rate r>0, set b=0 at handoff. From handoff state (x0,v0,a0),
  a(t)=a0*exp(-r*t),
  v(t)=v0+(a0/r)*(1-exp(-r*t)),
  x(t)=x0+(v0+a0/r)*t-(a0/r^2)*(1-exp(-r*t)).
Thus v tends to v0+a0/r. Unless this equals zero exactly, position is unbounded
in one direction. Even v0=0 does not suffice if a0 is nonzero. A threshold
|vhat|<=epsilon with sensor error ev gives only |v|<=epsilon+ev. It cannot
justify either rest or a permanent position tube under b=0.

A constructive hold law for the same changing-rate model
Take a fixed position reference c and choose the effective acceleration target
  b = -8*(x-c) - 6*v - a/2.
The coefficients carry the SI units needed to make b an acceleration. Define
  z1=x-c, z2=x-c+v/4, z3=x-c+v/2+a/16.
For q=r/8 in [1,3/2], direct substitution gives
  z1'=4*(-z1+z2),
  z2'=4*(-z2+z3),
  z3'=4*((1-q)*z1+3*(q-1)*z2+(2-3*q)*z3).
The cube |zi|<=R has inward vector fields on all faces. For the last pair of
faces, the outward absolute cross contribution is 4*(q-1)*R and the inward
coefficient is (3*q-2)*R before the outer factor 4. Their difference is
(2-q)*R>=R/2. The first two rows are inward or tangent. This yields a useful
position tube c-R<=x<=c+R if invariance is proved for actual trajectories.
A tangent-face calculation alone is not a complete invariant proof: use
uniqueness, a strict inflated barrier, or a valid maximum-norm comparison.
Handle R=0 separately or in the general proof.

The hold command is b=8*z1-8*z2-8*z3, hence |b|<=24*R inside the cube. If target
saturation is included, the capture contract must enforce this command range.
The negative braking-target assumption b<=-1.2 ends at handoff. It must not be
silently carried over to the hold mode, which can command positive acceleration.
For true v=0 and a=-1.2, choosing c=x+a/32 and R=-a/32=.0375 gives the nonempty
initial tuple (z1,z2,z3)=(R,R,-R). The cube spans [x-.075,x] and its command bound
is .9 m/s^2. This is a mathematical handoff example, not a physical mechanism.

Disturbance placement matters
If w is added to the physical effective target b, then the transformed z3
gets an additive r*w/16=q*w/2. The stated cube remains inward for |w|<=2*R:
q*|w|/2<=q*R, while the inward margin is 4*(2-q)*R; the worst q=1.5 leaves
.5*R of slack. If w instead denotes a disturbance directly in z3', its units
and admissible bound differ. State which definition is used. With additive
physical-target disturbance, total effective-target magnitude is <=26*R under
this sufficient bound. A nonzero disturbance floor sets a minimum tube radius.

A simpler conservative proof route
If the cube proof is costly, E=z1^2+z2^2+z3^2 decreases for the same law.
Write D=E'/4. At q=1,
 -D=z1^2+(z1-z2)^2+(z2-z3)^2+z3^2.
At q=3/2,
 -D=2*(z1-z2/2+z3/4)^2+(3/2)*(z2-3*z3/2)^2+(3/2)*z3^2.
D is affine in q, so these identities prove nonincrease throughout the rate
interval. A scalar derivative comparison then gives a looser position tube.
This is a fallback, not a replacement for a tighter checked cube theorem.

Noisy state capture
Acceleration error matters as well as velocity error. For measured x,v,a and
absolute errors ex,ev,ea, enclose the three uncentred transformed coordinates
  x,
  x+v/4,
  x+v/2+a/16
with respective radii ex, ex+ev/4 and ex+ev/2+ea/16. Let L be the minimum lower
endpoint and U the maximum upper endpoint. Then c=(L+U)/2 and R=(U-L)/2 give a
nonempty cube enclosure. After latency propagation, require U<=.15 to preserve
the existing global travel limit. Merely proving an arbitrary c+R bound does
not close the old safety claim. Also prove safety during the command latency.
All coordinates share the position error; separate interval radii are sound
but conservative. Do not call the independent-box enclosure exact.

The old EventStop contract only bounds b above. It gives no lower acceleration
bound for later two-sided capture. Add a lower target bound and an initial lower
acceleration bound, or use a measured acceleration interval and a justified
finite-latency jerk bound. Do not derive these from the old one-sided theorem.
The hold law assumes continuous state feedback. Finite sampling of that hold
law needs a separate error/disturbance reduction or a sampled invariant proof.
A noisy trigger, an ideal continuously evaluated hold law, and a sampled hold
implementation are three different contracts.

Detection and liveness
An absolute-value velocity band can be skipped between samples. A capture test
can be sound without ever becoming true. Do not claim detector liveness from
safe capture alone. A crossing trigger vhat<=theta, with the preceding sample
vhat>theta, sample gap <=h and |a|<=A, gives the current true-velocity bounds
 theta-ev-A*h < v <= theta+ev.
This avoids assuming that a sample lands inside a narrow symmetric band. It
still needs an initial/final case and a proof that a triggering sample occurs.
The sampling clock and command latency must be explicit, rather than counted
only as initial braking delay.

Publication boundary
This can close a useful gap between a stopping bound and safe mode handoff.
It does not by itself prove maintained zero velocity: the cube proves bounded
position. Nor does it establish physical rest, a friction-brake force law,
PL d/e compliance, hardware validation, or novelty over robust invariant-set
control. A coherent paper needs the full composition and a fair comparison.

RobustHold supplies the actual physical-to-transformed ODE identity. Its
finite_barrier proves strict first contact impossible using the left slope.
An expanding radius makes every first contact strict, and a final limit
removes that expansion. This resolves the tangent-face concern and includes

The equilibrium witness establishes a nonempty hold contract, but does not

Handoff requires equality of all three actual state coordinates between the
end of the delay and the start of holding. It resets none of x,v,a. It derives
both the position tube and the effective-target authority bound from the
capture and invariant theorems. The delay and hold are allowed to have a jerk
change at the switch, with state continuity preserved. Holding does not retain
the earlier negative-target braking requirement. This is the intended change
of operating mode.

ReleaseCounterexample defines an actual constant-rate zero-target trajectory.
It proves that its initially zero velocity and residual acceleration -1 cause
position to pass every finite rear limit. This refutes bounded-position safety
for that release rule; it does not claim every zero-target release violates a
forward-only limit. This distinction should remain explicit in explanations.

The new result is a bounded-position hold tube. It does not assert exact rest,
convergence, an implemented sampled hold law, saturating-actuator dynamics,
or a complete original-request-to-indefinite-hold implementation. RobustHold's
finite horizon is arbitrary, but existence for all future time remains an
assumption if the result is presented as permanent holding.
