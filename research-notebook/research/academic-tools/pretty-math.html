Pretty mathematics,
without Maple.

Use SymPy + JupyterLab for symbolic calculations with nicely rendered equations. Add SciPy + matplotlib for numerical experiments and figures. These are my recommended small, free research stack.

If the missing part is specifically the traditional worksheet GUI, try wxMaxima first. This is a workflow recommendation, not a claim of full Maple compatibility.

Calculate

A computer algebra system manipulates expressions, solves equations, and differentiates them. Pretty printing makes its results readable.

Present

Typesetting and animation tools turn the mathematics into a paper, figure, or explanation. Attractive output does not establish truth.

Verify

Lean checks a formal proof against its exact statement and assumptions. Keep that evidence separate from CAS output and numerical experiments.

A pretty version of our actuator model

For one held command u, constant rate r > 0, and initial state (x₀, v₀, a₀), the equations are x′ = v, v′ = a, a′ = r(u − a). Here is the exact segment:

a(t) = u + (a0 − u) e−rt
v(t) = v0 + ut + (a0 − u) 1 − e−rtr
x(t) = x0 + v0t + ut22 + (a0 − u) [tr − 1 − e−rtr2]

Paste this into a Python notebook. It renders each equation, checks the three differential identities and initial values symbolically, and can export the expression as LaTeX. In a plain Python terminal, it falls back to Unicode pretty printing.

import sympy as sp
try:
    from IPython.display import display
except ImportError:
    display = sp.pprint

sp.init_printing(use_unicode=True)
t = sp.symbols("t", nonnegative=True)
r = sp.symbols("r", positive=True)
x0, v0, a0, u = sp.symbols("x_0 v_0 a_0 u", real=True)

e = sp.exp(-r*t)
a = u + (a0-u)*e
v = v0 + u*t + (a0-u)*(1-e)/r
x = x0 + v0*t + u*t**2/2 + (a0-u)*(t/r - (1-e)/r**2)

for name, expr in [("x", x), ("v", v), ("a", a)]:
    display(sp.Eq(sp.Function(name)(t), expr))

residuals = [sp.diff(x, t)-v, sp.diff(v, t)-a,
             sp.diff(a, t)-r*(u-a)]
assert all(sp.simplify(q) == 0 for q in residuals)
assert [q.subs(t, 0) for q in (x, v, a)] == [x0, v0, a0]

# Copy this string into a LaTeX equation environment:
print(sp.latex(x))
