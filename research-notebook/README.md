## Evidence and toolchains

The accepted digital-hold follow-up proves all-time containment for supplied sampled
executions with total measurement age at most 1 ms, changing response, bounded sensor
errors and explicit command clipping. It derives the feedback mismatch instead of
assuming it. A checked nonconstant dispatch witness exercises derivative jumps.
Independent copied-source builds, axiom audits, separate kernel checks and negative
controls passed. The first sample and dispatch must both occur at hold time zero.
General existence, delayed braking-to-hold composition, precision standstill, hardware
and comparative value remain open. This is a team-review artifact, not submission
readiness. See the new review packet before using any result from that pod.

This notebook is separate from the root `ControlsLean` library. Its main project uses Lean 4.35.0;
the root library currently uses a different pin. Keep the notebook's `lake-manifest.json` and
`lean-toolchain` files unchanged when replaying its evidence. Importing these files does not make
them part of the root build or its CI coverage.

The tracking package contains 34 checked statements, including helper lemmas, plus a 144-case
numerical comparison and independent critique. A separate seven-statement followup checks the
cost of bounded command-filter error and limits on continuity at replans. That followup assumes
the filter-error bound. A later 16-statement pod result derives a joint bound from the actual
filter dynamics under explicit budgets. Those budgets require a fast filter. A separate
25-statement result proves homogeneous stability for a slower filter across the full uncertain
actuator-rate interval. It does not prove forced tracking performance. The forced-response
screen and its grade record which illustrative cases fail the requested position tolerance.

The earlier steadiness package contains 16 checked theorem statements. Each proof package
preserves its verifier, source hashes, axiom audit, kernel replay logs, and rejected false
mutations. Progress grades apply to the named milestone, not publication readiness.
Other folders have their own scopes and verification records. Some contain incomplete attempts
and deliberate negative tests. A count of `.lean` files is not a count of proved results.

The later direct-reference package adds 25 statements. It binds eight exact motion phases to
the existing uncertain-lag tracker and proves a continuous-time position-error bound of 0.2 mm
through 1.5 seconds. Its independent review audits 579 statements including 554 inherited ones.
The endpoint velocity and acceleration bounds are too coarse to establish physical stopping.
The two slow filters still fail the fixed numerical comparison. The robot-motion proposal uses
a retained reference history and an exact admission guard; its preflight acceptance is separate
from independent acceptance of its formal proof and Ruckig comparison. The finite certificate and
72-case comparison have passed independent computational review. The periodic input
aligns with a filter frequency zero, and the filter responds more slowly to a real step.
The harder 144-case gate preserves two native reconstruction tolerance failures. Its
canonical polynomial results and their scope have a separate review record. The fourteen-page
note distinguishes the accepted FIR certificate from numerical Ruckig comparisons and
retains the filter failures under irregular, random, and biased requests. The native-state
repair passed finite reconstruction and independent physical replay with unchanged
inputs and tolerances. All task decisions remain unchanged. Tiny phase counts
change command variation, so small position changes do not imply every metric
is unchanged. The portable FIR proof bundle passed a fresh 44-module replay and
independent kernel checks. The rounded-handoff addition now binds all 886 pieces
and 874 joins of the 12 frozen native paths to a conditional Lean tracking
bound of 0.128125000188 mm, with full time coverage. Its independent review
rebuilt 46 local modules and replayed 13 modules with the separate kernel checker.
The JSON-to-Lean binding is independently audited, not a verified parser.
Task-goal failures remain unchanged. A new isolated-task theorem proves conditional
hold, progress, and position arrival after old reference tails have completed.
The new reversal comparison gives all three methods the same requests and timing.
Native Ruckig variants each pass 18/24 tasks; the jerk-only FIR method passes 6/24.
An accepted FIR return violates acceleration, and the farther reversal is rejected.
Independent replay covers all 144 traces with no decision mismatches. A Lean witness
also checks jerk-guard acceptance alongside acceleration 21/32 > 1/2 m/s².
The task proof has a fresh 49-module review, 13 kernel replays, and five rejected
false controls. It does not prove physical rest or general mid-motion task changes.
