ASSESSMENT

The draft is a credible internal technical report after the concrete corrections
below. It is not submission-ready. Its central formulas match the checked
certificate interface, and its separation of nominal higher-dimensional proofs,
two-state robustness, exact arithmetic, and physical validation is sound. No new
control theorem or solved open problem is claimed. The strongest remaining
publication gap is evidence of a distinct contribution: a small collection of
known ingredients plus three elementary plants does not yet establish novelty.

Confidence is high in the specific source/text discrepancies reported here,
moderate in the novelty assessment, and intentionally unspecified for acceptance
at any venue. The literature review is bounded, not proof that no prior artifact
does the same thing. Author details are appropriately deferred to the user.

RESULTS THE DRAFT CURRENTLY UNDERREPORTS

7. Include the nominal intersample result already proved in HeldModels.
   Location: after line 84, or as a short proposition adjoining the sample bound.
   Jerk.intersample_energy and Planar.intersample_energy establish
       E(segment(t,z)) <= E(z)  for 0 <= t <= 1/2.
   Their sampled_segment_bound theorems then establish, for the actual held-step
   recurrence z_(n+1) = segment(h_n,z_n), hmin >= 0 and
   hmin <= h_n <= 1/2,
       E(segment(t,z_n)) <= (1 - hmin/M)^n E(z_0)
   for every n and every 0 <= t <= h_n. Here c=1, M=24 for jerk, and
   M=1422684/95123 for planar. This is a useful formal conclusion beyond sample
   states alone. Preserve its scope: it is indexed by sample and local elapsed
   time. HeldModels does not yet prove uniqueness of arbitrary ODE solutions,
   global real-time stitching, or non-Zeno coverage. There is no higher-dimensional
   perturbed/rounded version of this theorem.

8. Reconcile the new active-saturation example before freezing the manuscript.
   Location: line 149 currently proposes an active-saturation transient as future
   work. SaturatedEntry.lean now contains recovery_guarantee, which is absent
   from this draft. This review read its statement but did not newly build or
   audit that module; include it only after the parent verification confirms it.
   Its exact scope is one initial state (x,v)=(1,0), delta=1/10000, U=1,
   h_n=1/10 and w_n=0 for the first 26 steps. Clipping is active for the first
   four commands. All sampled energies are <=5; from sample 26 onward they are
   <=1/10 for arbitrary future h_n in [1/20,1/2] and |w_n| <=1/4000.
   This is a useful checked finite-prefix-to-invariant-tail composition, not a
   regional saturated basin, not jitter-robust recovery during the prefix, and
   not an intersample safety theorem for the active-saturation episode.
   It does not invalidate the existing budget-forces-inactivity result: the
   recovery starts outside that small certified invariant region.

PUBLICATION CONTRIBUTION GAPS

   Existing safe-envelope certificate pipelines already defeat a broad novelty

   Do not claim these tools lack a feature merely because it was not found in

10. Evaluate a concrete advantage on the same certification objects.
   Current timings demonstrate feasibility, not superiority or scalability.
   A useful next experiment compares direct polynomial tactics and the proposed
   reusable certificate method on the same residual matrices, then compares an
   applicable existing interval certificate framework. Report successful and
   failed cases, proof/certificate size, interval partitions, degree/state-size
   growth, generation and replay time separately, and sampling-bound conservatism.
   Do not compare unlike safety properties or use unsupported competing-tool
   failures as evidence of an advantage.
   Current manifest data can already add generated-source sizes of 6682, 6910,
   9586, and 16671 bytes, with partition counts 1,1,1,2. These are source sizes,
   not proof-term or binary sizes. Record hardware and Python/SymPy versions if
   reporting reproducible performance. The existing single-run disclaimer is good.

11. State the model-class limitation of the current benchmarks.
   All three nominal plants have nilpotent open-loop dynamics, making their
   zero-order-hold transition exactly polynomial. The coupled gain matrices do
   exercise off-diagonal reasoning, but do not add a nonnilpotent plant mode.
   A motor lag, damped oscillator, or other nonnilpotent plant generally needs
   matrix-exponential semantics or a rigorously bounded polynomial remainder.
   The current arbitrary-polynomial certificate interface alone supplies neither.
   A meaningful application inside the exact-polynomial class could be enough
   for a focused artifact paper; a broader controls claim needs this distinction.

12. Provide a claim-to-theorem and artifact-replay map.
   Add a compact appendix/table linking paper claims to named Lean declarations,
   input JSON, generated modules, and validation scripts. Distinguish generic
   library statements from generated instances and explicit model bridges.
   Bind all sources to the archive/commit used for the report, give a clean replay
   command and dependencies, and obtain an independent clean-environment replay.
   The current manifest proves a particular local run; it does not alone prove
   that a distributed source archive contains every necessary dependency.
