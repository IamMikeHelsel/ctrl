Meaning and proof reading
checkSuccessor_real_iff states the exact rational Boolean contract: positive
h, nonnegative A, and reference acceleration within A at every real time
t >= current. The rational-to-real cast is explicit. same_acceptance gives
the same true/false acceptance as checkAcceleration, including invalid
parameter rejection. It does not claim identical candidate-point lists.

For any time inside the future knot range, the proof chooses the last guard
point at or before it and the first point after it. No event knot lies in
that open cell. Affine jerk therefore identifies each nonflat stationary
point. Equal endpoint jerk uses a separate constant-jerk argument. A zero
jerk plateau retains its endpoint acceleration bound. After the last knot,
acceleration is zero. The current point is always checked. List.min? takes
a strictly later point, so repeated knots do not create zero-width cells.
There is no externally trusted sort and no division-by-zero obligation in
the flat branch.

Limits and next productive gate
This theorem is about a declared scalar reference. It does not bound actual
arm acceleration, velocity, dispatch latency, saturation or task completion.
It also does not make a finite execution-time selector complete over all
possible trajectories. The independent accepted history-pruning result is
a separate equivalence and is not silently incorporated here.

Continue with a sufficient rational velocity admission condition on these
same knot cells. Cubic Bernstein controls can give a simple finite check,
provided the polynomial identity is proved. Call it sufficient, not exact.
Then compose that condition with the existing A/J candidate contract. Keep
physical task completion and measured implementation cost as separate gates.
