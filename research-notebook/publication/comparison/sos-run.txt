FIXED OBJECT
A(h) = [[1-h^2, h-(3/2)h^2], [-2h, 1-3h]].
P = [[5,1],[1,1]], c=1, H=1/2.
The theorem is, for every real h,x,v,
  0 <= h -> h <= 1/2 -> residual(1,h,x,v) >= 0.
The residual is exactly the polynomial extension of
  [x,v] ((P-A(h)^T P A(h))/h - I) [x,v]^T.
A separate exact SymPy check against the benchmark JSON confirms the polynomial
identity and the eight-square expansion (SOSExactIdentity.json). That symbolic
check is supporting evidence; the accepted nonnegativity proof is Lean-checked.

FROZEN WITNESS DERIVATION
Set q=1-2h. Then residual = h*sigma0 + (1/2-h)*sigma1, where
  sigma0 = 24 [q(x+3v/16)]^2 + (389/32)(qv)^2
           + 35 [h(x+17v/70)]^2 + (94/35)(hv)^2,
  sigma1 = 6(qx)^2 + 6(qv)^2
           + 112 [h(x+17v/56)]^2 + (943/28)(hv)^2.
All eight rational weights are positive. The two multipliers are exactly the
two interval hypotheses. The reifier atoms are h,x,v (indices 0,1,2), with
constraint indices 0 for h and 1 for 1/2-h.
This follows by writing the existing cubic Bernstein certificate at t=2h:
  C0(1-t)^3 + 3C1*t(1-t)^2 + 3C2*t^2(1-t) + C3*t^3,
then using each 2x2 coefficient's exact LDL square decomposition and grouping
the first/third terms under (1/2-h), second/fourth under h. The resulting
witness is independently accepted by SOS's rational checker but shares the
original witness information; do not present it as independent discovery.
