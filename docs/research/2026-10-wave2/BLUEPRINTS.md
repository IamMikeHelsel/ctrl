## Shared conventions

These follow ctrl's playbook.

* Use `quad M x = x ⬝ᵥ (M *ᵥ x)` (`ControlsLean.Controls.quad`, re-exported by `ControlsLean.Tactics`) in place of `Matrix.PosDef` wherever possible. `SymPSD`, `LoewnerLE` (DAREExistence.lean:58,68) and `IsSchurStable`, `IsDetectable` (DAREDetectable.lean:80,90) are the existing predicates.
* Trajectories are `ℕ → n → ℝ`, defined by recursion (`lqrTraj`, LQROptimality.lean:34). Continuous-time hypotheses are `HasDerivAt` facts supplied by the caller, following the ManipulatorTracking.lean pattern. This means ODE existence is never needed.
* **Matrix-valued derivatives must be entrywise.** In Mathlib, `Matrix` has no global normed-group instance (`Mathlib/Analysis/Matrix/Normed.lean:187` is a `protected def`, used as a local or scoped instance). The grep also found no `HasDerivAt.matrix_mul`, `HasDerivAt.mulVec` or `HasDerivAt.dotProduct`. ROB-01 therefore defines `HasMatDerivAt X X' t := ∀ i j, HasDerivAt (fun s => X s i j) (X' i j) t`. It builds this from `HasDerivAt.sum` (Deriv/Add.lean:222) and `HasDerivAt.mul` (Deriv/Mul.lean:254). This is roughly 60 LOC of shared helpers, worth putting in `ControlsLean/Tactics/` for reuse.
* Rank-free linear algebra: "full row rank" is stated as "trivial left kernel" (`η ᵥ* M = 0 → η = 0`). That form is what proofs actually consume.

### 1.2 Lean statements

File: `ControlsLean/Estimation/HInfFilter.lean`.

```lean
import ControlsLean.Controls.BoundedRealHInf
import ControlsLean.Estimation.InformationFilter

namespace ControlsLean.Estimation

open Matrix BigOperators ControlsLean.Controls ControlsLean.Tactics

variable {n r p q : Type*} [Fintype n] [Fintype r] [Fintype p] [Fintype q] [DecidableEq n]

/-- Measurement-updated information `Π = Y + CᵀC`, where `Y = P⁻¹` is the prior information. -/
def hinfInfoPost (Y : Matrix n n ℝ) (C : Matrix p n ℝ) : Matrix n n ℝ := Y + Cᵀ * C

/-- H∞ feasibility matrix `F = Y + CᵀC − γ⁻² LᵀL`; the filter exists iff `F ≻ 0` at every step. -/
noncomputable def hinfFeas (Y : Matrix n n ℝ) (C : Matrix p n ℝ) (L : Matrix q n ℝ) (γ : ℝ) :
    Matrix n n ℝ :=
  hinfInfoPost Y C - (γ ^ 2)⁻¹ • (Lᵀ * L)

/-- A posteriori gain `K_f = Π⁻¹ Cᵀ` (equal to `P Cᵀ (I + C P Cᵀ)⁻¹` when `Y = P⁻¹`). -/
noncomputable def hinfGain (Y : Matrix n n ℝ) (C : Matrix p n ℝ) : Matrix n p ℝ :=
  (hinfInfoPost Y C)⁻¹ * Cᵀ

/-- Predicted covariance `P⁺ = A F⁻¹ Aᵀ + G Gᵀ`; the next information matrix is its inverse. -/
noncomputable def hinfPredCov (A : Matrix n n ℝ) (G : Matrix n r ℝ) (F : Matrix n n ℝ) :
    Matrix n n ℝ :=
  A * F⁻¹ * Aᵀ + G * Gᵀ

/-- Certificate that `Y` is an admissible information sequence of the H∞ filter at level `γ`. -/
def IsHInfInfoSeq (A : Matrix n n ℝ) (G : Matrix n r ℝ) (C : Matrix p n ℝ)
    (L : Matrix q n ℝ) (γ : ℝ) (Y : ℕ → Matrix n n ℝ) : Prop :=
  ∀ k, SymPSD (Y k) ∧ (hinfFeas (Y k) C L γ).PosDef ∧
    hinfPredCov A G (hinfFeas (Y k) C L γ) * Y (k + 1) = 1

/-- Prior error `e_k = x_k − x̂_{k|k−1}` for the plant `x⁺ = A x + G w`, `y = C x + v` and the
filter `x̂_{k|k} = x̂_{k|k−1} + K_f(y_k − C x̂_{k|k−1})`, `x̂_{k+1|k} = A x̂_{k|k}`. -/
noncomputable def hinfPriorErr (A : Matrix n n ℝ) (G : Matrix n r ℝ) (C : Matrix p n ℝ)
    (Y : ℕ → Matrix n n ℝ) (e₀ : n → ℝ) (w : ℕ → r → ℝ) (v : ℕ → p → ℝ) : ℕ → n → ℝ
  | 0 => e₀
  | k + 1 =>
      A *ᵥ (hinfPriorErr A G C Y e₀ w v k -
        hinfGain (Y k) C *ᵥ (C *ᵥ hinfPriorErr A G C Y e₀ w v k + v k)) + G *ᵥ w k

/-- Posterior error `ε_k = x_k − x̂_{k|k}`; the estimated signal is `z = L x`. -/
noncomputable def hinfPostErr (A : Matrix n n ℝ) (G : Matrix n r ℝ) (C : Matrix p n ℝ)
    (Y : ℕ → Matrix n n ℝ) (e₀ : n → ℝ) (w : ℕ → r → ℝ) (v : ℕ → p → ℝ) (k : ℕ) : n → ℝ :=
  hinfPriorErr A G C Y e₀ w v k -
    hinfGain (Y k) C *ᵥ (C *ᵥ hinfPriorErr A G C Y e₀ w v k + v k)

/-- The plant/filter interconnection produces exactly `hinfPriorErr`. -/
theorem hinf_filter_error_eq {A : Matrix n n ℝ} {G : Matrix n r ℝ} {C : Matrix p n ℝ}
    {Y : ℕ → Matrix n n ℝ} {w : ℕ → r → ℝ} {v : ℕ → p → ℝ} (x xh : ℕ → n → ℝ)
    (hx : ∀ k, x (k + 1) = A *ᵥ x k + G *ᵥ w k)
    (hxh : ∀ k, xh (k + 1) = A *ᵥ (xh k + hinfGain (Y k) C *ᵥ (C *ᵥ x k + v k - C *ᵥ xh k))) :
    ∀ k, x k - xh k = hinfPriorErr A G C Y (x 0 - xh 0) w v k := by
  sorry

/-- (N1) Information-form measurement update (completion of squares, no inverses of `Y`). -/
theorem quad_info_update {Y : Matrix n n ℝ} (hY : SymPSD Y) {C : Matrix p n ℝ}
    (hΠ : IsUnit (hinfInfoPost Y C).det) (e : n → ℝ) (v : p → ℝ) :
    quad (hinfInfoPost Y C) (e - hinfGain Y C *ᵥ (C *ᵥ e + v)) ≤ quad Y e + v ⬝ᵥ v := by
  sorry

/-- (N2) Minimum-norm ("parallel sum") inequality: for `F ≻ 0` and `Y' = (A F⁻¹ Aᵀ + G Gᵀ)⁻¹`,
`(Aε + Gw)ᵀ Y' (Aε + Gw) ≤ εᵀ F ε + wᵀ w`. -/
theorem quad_le_of_predCov {A : Matrix n n ℝ} {G : Matrix n r ℝ} {F Y' : Matrix n n ℝ}
    (hF : F.PosDef) (hY' : hinfPredCov A G F * Y' = 1) (ε : n → ℝ) (w : r → ℝ) :
    quad Y' (A *ᵥ ε + G *ᵥ w) ≤ quad F ε + w ⬝ᵥ w := by
  sorry

/-- (N3) One-step H∞ dissipation inequality of the filter. -/
theorem hinf_filter_step {A : Matrix n n ℝ} {G : Matrix n r ℝ} {C : Matrix p n ℝ}
    {L : Matrix q n ℝ} {γ : ℝ} (hγ : 0 < γ) {Y Y' : Matrix n n ℝ} (hY : SymPSD Y)
    (hF : (hinfFeas Y C L γ).PosDef) (hY' : hinfPredCov A G (hinfFeas Y C L γ) * Y' = 1)
    (e : n → ℝ) (w : r → ℝ) (v : p → ℝ) :
    let ε := e - hinfGain Y C *ᵥ (C *ᵥ e + v)
    (L *ᵥ ε) ⬝ᵥ (L *ᵥ ε) + γ ^ 2 * quad Y' (A *ᵥ ε + G *ᵥ w) ≤
      γ ^ 2 * (quad Y e + v ⬝ᵥ v + w ⬝ᵥ w) := by
  sorry

/-- **Headline (EST-05)** — finite-horizon, time-varying H∞ a posteriori filter bound:
`Σ_{k<N} ‖L ε_k‖² + γ² e_Nᵀ Y_N e_N ≤ γ² (e₀ᵀ Y₀ e₀ + Σ_{k<N} (‖w_k‖² + ‖v_k‖²))`. -/
theorem hinf_filter_l2_gain {A : Matrix n n ℝ} {G : Matrix n r ℝ} {C : Matrix p n ℝ}
    {L : Matrix q n ℝ} {γ : ℝ} (hγ : 0 < γ) {Y : ℕ → Matrix n n ℝ}
    (hY : IsHInfInfoSeq A G C L γ Y) (e₀ : n → ℝ) (w : ℕ → r → ℝ) (v : ℕ → p → ℝ) (N : ℕ) :
    (∑ k ∈ Finset.range N,
        (L *ᵥ hinfPostErr A G C Y e₀ w v k) ⬝ᵥ (L *ᵥ hinfPostErr A G C Y e₀ w v k)) +
      γ ^ 2 * quad (Y N) (hinfPriorErr A G C Y e₀ w v N) ≤
    γ ^ 2 * (quad (Y 0) e₀ + ∑ k ∈ Finset.range N, (w k ⬝ᵥ w k + v k ⬝ᵥ v k)) := by
  sorry

/-- Stationary corollary: a constant `Y` solving the H∞ filtering ARE gives a uniform-in-`N`
ℓ²-gain bound `≤ γ`, and the closed-loop error matrix `A (I − K_f C)` is Schur stable when
`(A (I − K_f C), L (I − K_f C))` is detectable. -/
theorem hinf_filter_stationary [DecidableEq p] {A : Matrix n n ℝ} {G : Matrix n r ℝ}
    {C : Matrix p n ℝ} {L : Matrix q n ℝ} {γ : ℝ} (hγ : 0 < γ) {Y : Matrix n n ℝ}
    (hYs : SymPSD Y) (hF : (hinfFeas Y C L γ).PosDef)
    (hare : hinfPredCov A G (hinfFeas Y C L γ) * Y = 1)
    (hdet : IsDetectable (A * (1 - hinfGain Y C * C)) (L * (1 - hinfGain Y C * C))) :
    IsSchurStable (A * (1 - hinfGain Y C * C)) := by
  sorry

/-- Kalman limit: with `L = 0` the H∞ recursion is the information-form Kalman recursion. -/
theorem hinfFeas_zero_L (Y : Matrix n n ℝ) (C : Matrix p n ℝ) (γ : ℝ) :
    hinfFeas Y C (0 : Matrix q n ℝ) γ = hinfInfoPost Y C := by
  simp [hinfFeas]
```

### 1.3 Lemma DAG

```
quad_* calculus (ctrl) ──┬─► N1 quad_info_update ───────┐
SymPSD, PosDef (Mathlib) ┤                              ├─► N3 hinf_filter_step ─► N4 hinf_filter_l2_gain
                         └─► N2 quad_le_of_predCov ─────┘          │
hinf_filter_error_eq (induction) ──────────────────────────────────┤
schur_of_lyapunov_le_detectable (ctrl BRL) ────────────────────────┴─► N5 hinf_filter_stationary
kalman_postVar_information_equiv (ctrl) ─► N6 Kalman-limit corollaries
hinf_stage_completion_of_squares (ctrl) ─► N7 (optional) error-system BRL for an arbitrary gain K
```

**N0, `hinf_filter_error_eq`.** Induction on `k`, unfolding both recursions. The `x k − xh k` algebra is `mulVec_sub`/`mulVec_add` plus `abel`. Mathlib: `Matrix.mulVec_add` (Data/Matrix/Mul.lean:817), `Matrix.sub_mulVec` (:1099), `Matrix.add_mulVec` (:822). About 30 LOC.

**N1, `quad_info_update`.** Set `y := C e + v`, `η := Π⁻¹ Cᵀ y` and `ε := e − η`. Because `Π` is symmetric (`Y` symmetric, CᵀC symmetric) and `Π η = Cᵀ y` (by `mul_nonsing_inv_cancel_left`), expanding gives

  `quad Y e + ‖v‖² − quad Π ε = ‖y‖² − quad Π η = ‖y − C η‖² + quad Y η ≥ 0`.

The second equality uses `quad Π η = η ⬝ᵥ Cᵀ y = (Cη) ⬝ᵥ y` and `quad Π η = quad Y η + ‖Cη‖²`. No inverse of `Y` is needed, so a singular prior (`Y = 0`, an unknown initial state) is allowed. Mathlib: `Matrix.mul_nonsing_inv_cancel_left` (LinearAlgebra/Matrix/NonsingularInverse.lean:232), `Matrix.transpose_nonsing_inv` (:200), `Matrix.dotProduct_mulVec` (Data/Matrix/Mul.lean:786), `Matrix.vecMul_transpose` (:1128), `dotProduct_comm` (:88), `dotProduct_sub` (:237). ctrl: `quad_add`, `quad_transpose_mul_self`. About 70 LOC.

**N2, `quad_le_of_predCov`** (the dual-BRL heart). Set `z = Aε + Gw`, `λ := Y' z`, `ε* := F⁻¹ Aᵀ λ` and `w* := Gᵀ λ`. Since `F` is symmetric with `F F⁻¹ = 1`, we get `ε*ᵀ F ε = λᵀ A ε`, `w*ᵀ w = λᵀ G w`, and `ε*ᵀ F ε* + ‖w*‖² = λᵀ P⁺ λ = λᵀ z` (using `P⁺ Y' = 1`). Hence

  `quad F ε + ‖w‖² = quad F (ε − ε*) + ‖w − w*‖² + λᵀ z ≥ λᵀ z = quad Y' z`.

The last step needs no symmetry of `Y'`: `quad Y' z = z ⬝ᵥ (Y' *ᵥ z) = z ⬝ᵥ λ`. Mathlib: `Matrix.PosDef.det_pos` (LinearAlgebra/Matrix/PosDef.lean:549) gives `IsUnit F.det`, then `Matrix.mul_nonsing_inv` (NonsingularInverse.lean:209) and `Matrix.transpose_nonsing_inv` (:200). ctrl: `quad_nonneg_of_posDef`, `dotProduct_self_nonneg'`. About 80 LOC. Numerically verified (Appendix B).

**N3, `hinf_filter_step`.** Write `F = Π − γ⁻²LᵀL`. Then `γ²·quad F ε = γ²·quad Π ε − ‖Lε‖²` (by `quad_sub`, `quad_smul_mat`, `quad_transpose_mul_self`, `field_simp`). Chain N2 (scaled by γ²), this identity, and N1 (scaled by γ²). `Π` is invertible: `Π = F + γ⁻²LᵀL`, which is PosDef by `Matrix.PosDef.add_posSemidef` (PosDef.lean:247), then `.det_pos`. About 50 LOC.

**N4, headline.** Induction on `N` in exactly the shape of `hinf_finite_horizon_identity`, with `Finset.sum_range_succ` (to_additive of `Finset.prod_range_succ`, Algebra/BigOperators/Group/Finset/Basic.lean:560) and `linarith`. About 50 LOC.

**N5, stationary.** Set `w = v = 0` in N3 with `Y' = Y` to get `‖L(I−K_fC)e‖² ≤ γ²quad Y e − γ²quad Y (A(I−K_fC)e)`. That is exactly the hypothesis shape of `schur_of_lyapunov_le_detectable` with `P := γ² • Y`. About 40 LOC.

**N6, Kalman limit.** With `L = 0`: `hinfFeas = Π` and `hinfPredCov = A Π⁻¹ Aᵀ + GGᵀ`, the information-form Kalman time update. Link to the covariance form through `kalman_postVar_information_equiv`. About 40 LOC.

**N7 (optional), error-system BRL bridge.** For any gain `K`, apply `hinf_stage_completion_of_squares` to `(A − KC, fromCols G (−K), L, 0)`. Time-varying storage comes free: apply it with `P := P⁺`, then add `quad P⁺ x − quad P x` to both sides. Mathlib: `Matrix.fromCols` (Data/Matrix/ColumnRowPartitioned.lean:39), `Matrix.fromCols_mulVec` (:212), `Fintype.sum_sum_type` (to_additive of `Fintype.prod_sum_type`, Data/Fintype/BigOperators.lean:265). About 90 LOC.

**Missing Mathlib API**: none on the critical path. Mathlib's PSD Schur complement exists (`Matrix.PosDef.fromBlocks₁₁`/`₂₂`, PosDef.lean:637/656), but this blueprint avoids it on purpose.

### 1.4 Hardest step, trick, estimate, risk

* **Hardest step.** The time update with matrix inverses (N2). The textbook route goes through Schur complements or Woodbury on block matrices.
* **Spectral-free trick.** The Lagrange-multiplier completion of squares (`λ = Y' z`) needs only `F F⁻¹ = 1` and `P⁺ Y' = 1`. It uses no Schur-complement API, no Woodbury, no Loewner-inverse antitonicity and no eigenvalues. N1 is the same trick in measurement-update form. The whole module is quadratic-form algebra in ctrl's existing style.
* **Correctness check.** It matters that the theorem is the **a posteriori** filter, with condition `Y + CᵀC − γ⁻²LᵀL ≻ 0`, which matches the frontier entry. The same storage `γ²P⁻¹` **fails** for the a priori output `L e_k` in 95% of random cases (Appendix B). Do not state the a priori version with this Riccati recursion.
* **Estimate.** ~450 LOC, 5–7 days. **Risk: low.** The main friction will be `PosDef` ↔ `quad` conversions (already solved in ctrl: `posDef_iff_quad_pos`, `quad_nonneg_of_posDef`) and the `let ε := …` in N3, which can be replaced by an explicit argument if `simp` struggles.

/-- SO(3) membership in ctrl's explicit style. -/
def IsRot (R : M3) : Prop := Rᵀ * R = 1 ∧ R.det = 1

/-- 3×3 adjugate as an explicit polynomial in `X` (true for *every* 3×3 matrix). -/

    2 * trace (adjugate X) = trace X ^ 2 - trace (X * X) := sorry
theorem IsRot.adjugate_eq {R : M3} (hR : IsRot R) : adjugate R = Rᵀ := sorry

/-! ### B. Attitude error function and its bounds -/

noncomputable def attErr (R Rd : M3) : ℝ := (1 / 2 : ℝ) * trace (1 - Rdᵀ * R)        -- Ψ
noncomputable def attErrVec (R Rd : M3) : V3 := (1 / 2 : ℝ) • vee (Rdᵀ * R - Rᵀ * Rd) -- e_R

  (1 / 2 : ℝ) • (trace (Rᵀ * Rd) • (1 : M3) - Rᵀ * Rd)

/-- **Key identity**: `‖e_R‖² = Ψ (2 − Ψ)` on SO(3) × SO(3). -/
theorem attErrVec_dot_self {R Rd : M3} (hR : IsRot R) (hRd : IsRot Rd) :
    attErrVec R Rd ⬝ᵥ attErrVec R Rd = attErr R Rd * (2 - attErr R Rd) := sorry
theorem attErr_nonneg {R Rd : M3} (hR : IsRot R) (hRd : IsRot Rd) : 0 ≤ attErr R Rd := sorry
theorem attErr_le_two {R Rd : M3} (hR : IsRot R) (hRd : IsRot Rd) : attErr R Rd ≤ 2 := sorry

    attErr R Rd = 0 ↔ R = Rd := sorry
/-- Lee–Leok–McClamroch bounds `½‖e_R‖² ≤ Ψ ≤ ‖e_R‖² / (2 − Ψ)` (the second on `Ψ < 2`). -/
theorem attErr_bounds {R Rd : M3} (hR : IsRot R) (hRd : IsRot Rd) :
    (1 / 2 : ℝ) * (attErrVec R Rd ⬝ᵥ attErrVec R Rd) ≤ attErr R Rd ∧
    (attErr R Rd < 2 →
      attErr R Rd ≤ (attErrVec R Rd ⬝ᵥ attErrVec R Rd) / (2 - attErr R Rd)) := sorry
theorem attErr_le_of_le {R Rd : M3} (hR : IsRot R) (hRd : IsRot Rd) {ψ : ℝ} (hψ : ψ < 2)
    (h : attErr R Rd ≤ ψ) :
    attErr R Rd ≤ (attErrVec R Rd ⬝ᵥ attErrVec R Rd) / (2 - ψ) := sorry
/-- `e_R` is fixed by the relative rotation: `(RdᵀR) e_R = e_R`. -/
theorem mulVec_attErrVec {R Rd : M3} (hR : IsRot R) (hRd : IsRot Rd) :
    (Rdᵀ * R) *ᵥ attErrVec R Rd = attErrVec R Rd := sorry

/-! ### D. Controller, closed loop, Lyapunov, exponential decay -/

/-- Lee–Leok–McClamroch attitude tracking moment. -/
noncomputable def leeMoment (J : M3) (kR kΩ : ℝ) (R Rd : M3) (Ω Ωd Ωddot : V3) : V3 :=
  -kR • attErrVec R Rd - kΩ • angVelErr R Rd Ω Ωd + Ω ⨯₃ (J *ᵥ Ω)
    - J *ᵥ (skew Ω *ᵥ ((Rᵀ * Rd) *ᵥ Ωd) - (Rᵀ * Rd) *ᵥ Ωddot)

theorem lee_closed_loop {J : M3} {kR kΩ : ℝ} {R Rd : M3} {Ω Ωd Ωdot Ωddot : V3}
    (hdyn : J *ᵥ Ωdot + Ω ⨯₃ (J *ᵥ Ω) = leeMoment J kR kΩ R Rd Ω Ωd Ωddot) :
    J *ᵥ (Ωdot + skew Ω *ᵥ ((Rᵀ * Rd) *ᵥ Ωd) - (Rᵀ * Rd) *ᵥ Ωddot) =
      -kR • attErrVec R Rd - kΩ • angVelErr R Rd Ω Ωd := sorry

noncomputable def leeLyap (J : M3) (kR c : ℝ) (R Rd : M3) (eΩ : V3) : ℝ :=
  (1 / 2 : ℝ) * quad J eΩ + kR * attErr R Rd + c * (attErrVec R Rd ⬝ᵥ (J *ᵥ eΩ))

/-- Generic exponential decay from `V' ≤ −β V` on `[0, ∞)`. -/
theorem le_exp_mul_of_hasDerivAt {V V' : ℝ → ℝ} {β : ℝ}

    ∀ t, 0 ≤ t → V t ≤ Real.exp (-β * t) * V 0 := sorry

/-- **Headline (ROB-01)**: exponential attitude tracking on the sublevel set `{Ψ ≤ ψ < 2}`.
Gains enter only through four explicit scalar margins `WR WΩ LR LΩ > 0`; any concrete gains
can be checked with `norm_num`. -/
theorem lee_attitude_exponential

    (hJlo : ∀ v : V3, λm * (v ⬝ᵥ v) ≤ quad J v)
    (hJhi : ∀ v : V3, (J *ᵥ v) ⬝ᵥ (J *ᵥ v) ≤ λM ^ 2 * (v ⬝ᵥ v))
    {kR kΩ c δ ψ : ℝ} (hkR : 0 < kR) (hkΩ : 0 < kΩ) (hc : 0 < c) (hδ : 0 < δ) (hψ : ψ < 2)
    (hWR : 0 < c * (kR - kΩ * δ / 2)) (hWΩ : 0 < kΩ - c * λM - c * kΩ / (2 * δ))
    (hLR : 0 < kR / 2 - c / 2) (hLΩ : 0 < λm / 2 - c * λM ^ 2 / 2)
    {R Rd : ℝ → M3} {Ω Ωd Ωdot Ωddot : ℝ → V3}
    (hR : ∀ t, IsRot (R t)) (hRd : ∀ t, IsRot (Rd t))
    (hRk : ∀ t, HasMatDerivAt R (R t * skew (Ω t)) t)
    (hRdk : ∀ t, HasMatDerivAt Rd (Rd t * skew (Ωd t)) t)
    (hΩ : ∀ t, HasVecDerivAt Ω (Ωdot t) t) (hΩd : ∀ t, HasVecDerivAt Ωd (Ωddot t) t)
    (hdyn : ∀ t, J *ᵥ Ωdot t + Ω t ⨯₃ (J *ᵥ Ω t) =

    let eΩ := fun t => angVelErr (R t) (Rd t) (Ω t) (Ωd t)

    ∀ t, 0 ≤ t →

        Real.exp (-β * t) * V 0 := sorry

### 2.3 Lemma DAG

```
A1 adjugate_eq_poly, trace_adjugate_fin_three  (fin_cases + ring)
A2 IsRot.adjugate_eq ──► A3 IsRot.sq_eq ──► A6 symm_part_sq ──► A7 quad_ge ──► B6 attErrJac_contract
        └──► A4 cross_mulVec ──► A5 skew_mulVec_of_isRot ──► B5 mulVec_attErrVec
A1+A2 ──► B1 attErrVec_dot_self ──► B2 nonneg/le_two/eq_zero ──► B3 attErr_bounds, attErr_le_of_le
C0 HasMatDerivAt.{mul,transpose,trace,mulVec}, HasVecDerivAt.dotProduct
C0+B5 ──► C1 hasDerivAt_attErr        C0+A5 ──► C2 hasDerivAt_attErrVec      C0 ──► C3 hasDerivAt_angVelErr
C3 ──► D1 lee_closed_loop
D2 V₀ = ½eΩᵀJeΩ + kRΨ is antitone (C1, D1)  ──► D3 invariance Ψ(t) ≤ ψ
D4 V̇ ≤ −WR‖eR‖² − WΩ‖eΩ‖²  (C1,C2,D1,B6, Young)  +  D5 LR‖eR‖²+LΩ‖eΩ‖² ≤ V ≤ UR‖eR‖²+UΩ‖eΩ‖² (B3,D3)
D6 le_exp_mul_of_hasDerivAt ──► HEADLINE lee_attitude_exponential
```

**A1.** `ext i j; fin_cases i <;> fin_cases j <;> simp [adjugate_fin_three, trace_fin_three, mul_apply, Fin.sum_univ_three] <;> ring`. These are degree-2 polynomial identities, the same shape as ctrl's `skew_cube`. Mathlib: `Matrix.adjugate_fin_three` (LinearAlgebra/Matrix/Adjugate.lean:382), `Matrix.trace_fin_three` (LinearAlgebra/Matrix/Trace.lean:221), `Matrix.det_fin_three` (LinearAlgebra/Matrix/Determinant/Basic.lean:820). About 25 LOC.

**A2.** `R * adjugate R = det R • 1 = 1` (`Matrix.mul_adjugate`, Adjugate.lean:263). Left-multiply by `Rᵀ` and use `RᵀR = 1`. About 10 LOC.

**A3.** Combine A1 with A2: `Rᵀ = R² − tR + sI`, and `s = tr(adj R) = tr Rᵀ = t` (`Matrix.trace_transpose`, Trace.lean:71). About 10 LOC.

**A4.** The polynomial identity `(Xa) ⨯₃ (Xb) = (adjugate X)ᵀ *ᵥ (a ⨯₃ b)` holds for all 3×3 `X` (`fin_cases` + `cross_apply` + `adjugate_fin_three` + `ring`). Then apply A2. Mathlib: `cross_apply` (LinearAlgebra/CrossProduct.lean:63). About 20 LOC.

**A5.** `skew (Rv) w = (Rv) ⨯₃ w = (Rv) ⨯₃ (R Rᵀ w) = R (v ⨯₃ Rᵀw)` by A4, then `skew_mulVec` and `ext`. About 15 LOC. **This closes the `hequiv` gap in SE3Kinematics.**

**A6.** `(R+Rᵀ)² = R² + 2I + Rᵀ²`. Substitute A3 and its transpose, then `module`/`abel` with `smul` arithmetic. About 25 LOC. **A7.** From A6, `(3−t)·quad S y = ‖S y‖² ≥ 0` (S symmetric). Case `3 − t > 0`: divide. Case `t = 3`: `‖Sy‖² = 0` gives `Sy = 0`, so `quad S y = 0`. Then `quad S y = 2 quad R y − (t−1)‖y‖²`. About 25 LOC.

**B1.** `‖e_R‖² = −⅛ tr((E−Eᵀ)²) = ¾ − ¼ tr(E²)` with `E = RdᵀR`. A coordinate identity: `vee`, then `fin_cases`, then `ring`. A3's trace (`tr E² = t² − 2t`) closes it. About 30 LOC. **B2.** `Ψ ≥ 0`: each `E_ii ≤ 1` from `EᵀE = 1` (column norms, using `Fin.sum_univ_three` and `nlinarith`). `Ψ ≤ 2`: from B1 (`Ψ(2−Ψ) ≥ 0` and `Ψ ≥ 0`). `Ψ = 0 ↔ R = Rd`: `tr E = 3` with all `E_ii ≤ 1` forces `E_ii = 1`, so the off-diagonal entries vanish and `E = 1`. About 50 LOC. **B3.** Scalar algebra from B1 and B2 (`div_le_iff₀`, `nlinarith`). About 25 LOC.

**B5.** `[E e_R]× = E [e_R]× Eᵀ` (A5) `= ½E(E−Eᵀ)Eᵀ = ½(E−Eᵀ) = [e_R]×`, using `EEᵀ = I`. Injectivity of `skew` comes from `vee_skew`. About 20 LOC.

**B6.** `4‖Cy‖² = t²‖y‖² − 2t·quad Eᵀ y + ‖y‖²`. This expression is linear in `r = quad E y/‖y‖²`, and A7 gives `r ∈ [(t−1)/2, 1]`. The upper end is Cauchy–Schwarz written as a square: `0 ≤ ‖y − Ey‖² = 2‖y‖² − 2 quad E y`. The endpoint values are `(t−3)(t+1) ≤ 0` and `t − 3 ≤ 0`, so a case split on the sign of `t` plus `nlinarith` finishes. About 40 LOC.

**C0.** Unfold `mul_apply`/`trace` to `Finset.sum`, then apply `HasDerivAt.sum` (Analysis/Calculus/Deriv/Add.lean:222), `HasDerivAt.mul` (Deriv/Mul.lean:254), `HasDerivAt.add` (Deriv/Add.lean:59), `HasDerivAt.sub` (:356) and `HasDerivAt.const_mul` (Deriv/Mul.lean:343). **D4.** `V̇ = −kΩ‖eΩ‖² + c(CeΩ)·(JeΩ) − c kR‖eR‖² − c kΩ eR·eΩ`. Bound the cross terms with polynomial Young inequalities: `2x·y ≤ δ‖x‖² + δ⁻¹‖y‖²`, proved from `0 ≤ quad 1 (δx − y)/δ`. ### 2.4 Hardest step, trick, estimate, risk

* **Hardest step.** The textbook proofs of `‖e_R‖² = Ψ(2−Ψ)`, `E e_R = e_R` and `‖C(E)‖ ≤ 1` all go through the axis–angle representation, which needs the existence of a rotation axis (an eigenvector for eigenvalue 1) and therefore the spectral theory of SO(3).
* **Spectral-free trick.** The 3×3 adjugate identity `adj X = X² − tr X·X + tr(adj X)·I` (a polynomial identity, `fin_cases; ring`) combined with `adj R = Rᵀ` gives `R² = tR − tI + Rᵀ`. That one equation implies `tr R² = t² − 2t` (hence B1), the cross-product equivariance A4/A5 (hence B5), and `S² = (3−t)S` for `S = R + Rᵀ − (t−1)I` (hence `S ⪰ 0` and B6). The proof never mentions eigenvalues or axes. It is consistent with ctrl's "dimension counting instead of Cayley–Hamilton" philosophy, using an explicit 3×3 identity in place of the general theorem.
* **Second-hardest step.** C0–C2: entrywise derivative plumbing with `Finset` sums of products. It is mechanical but long.
* **Estimate.** ~850 LOC, 8–11 working days. **Risk: medium.** `simp`/`ring` timeouts on 3×3 identities with nine symbolic entries are unlikely to be fatal (ctrl already proves `skew_cube`, `det_adjoint6`). `nlinarith` in B2/B6 may need hand-fed products. The headline's `let`-bound conclusion may need restating as separate lemmas if elaboration is slow.
* **Scope note.** The SE(3)/position loop (Lee 2010 quadrotor) is **not** in the 2-week scope. It adds coupling bounds between the thrust direction and attitude error. Budget another 1.5–2 weeks.

import ControlsLean.Controls.Observability

namespace ControlsLean.Estimation

open Matrix BigOperators ControlsLean.Controls

variable {n m p : Type*} [Fintype n] [Fintype m] [Fintype p] [DecidableEq n] [DecidableEq m]

/-- Depth-`L` block Hankel matrix with `N` columns: `H_L(u)_{(i,a), j} = u (j + i) a`. -/
def hankel (u : ℕ → m → ℝ) (L N : ℕ) : Matrix (Fin L × m) (Fin N) ℝ :=
  Matrix.of fun ia j => u (j + ia.1) ia.2

/-- State data matrix `X = [x₀ ⋯ x_{N−1}]`. -/
def stateData (x : ℕ → n → ℝ) (N : ℕ) : Matrix n (Fin N) ℝ := Matrix.of fun a j => x j a

/-- Persistency of excitation of order `L` over `N` columns, rank-free:
`H_L(u)` has trivial left kernel (full row rank `L·|m|`). -/
def PersistentlyExciting (u : ℕ → m → ℝ) (L N : ℕ) : Prop :=
  ∀ η : Fin L × m → ℝ, η ᵥ* hankel u L N = 0 → η = 0

theorem persistentlyExciting_iff_rank (u : ℕ → m → ℝ) (L N : ℕ) :
    PersistentlyExciting u L N ↔ (hankel u L N).rank = L * Fintype.card m := sorry

abbrev MatControllable (A : Matrix n n ℝ) (B : Matrix n m ℝ) : Prop :=
  Controllable (Matrix.toLin' A) (Matrix.toLin' B)

    MatControllable A B ↔
      ∀ ξ : n → ℝ, (∀ k < Fintype.card n, ξ ᵥ* (A ^ k * B) = 0) → ξ = 0 := sorry

      ∑ i ∈ Finset.range (Fintype.card n), c i • ((A ^ i) *ᵥ ξ) := sorry

    {d M : ℕ} (γ : ℕ → V) (c : ℕ → ℝ)
    (htail : ∀ j, M ≤ j → γ j = 0)
    (hrec : ∀ P < M, γ P = ∑ i ∈ Finset.range d, c i • γ (P + d - i)) :

if `(A,B)` is controllable and `u` is PE of order `L + n` over `N` columns, then
`[X; H_L(u)]` over `N + n` columns has trivial left kernel. -/

    {u : ℕ → m → ℝ} {x : ℕ → n → ℝ} (hx : ∀ k, x (k + 1) = A *ᵥ x k + B *ᵥ u k) {L N : ℕ}

    (h : ξ ᵥ* stateData x (N + Fintype.card n) + η ᵥ* hankel u L (N + Fintype.card n) = 0) :
    ξ = 0 ∧ η = 0 := sorry

theorem stateInput_surjective {A : Matrix n n ℝ} {B : Matrix n m ℝ} (hc : MatControllable A B)
    {u : ℕ → m → ℝ} {x : ℕ → n → ℝ} (hx : ∀ k, x (k + 1) = A *ᵥ x k + B *ᵥ u k) {L N : ℕ}

    ∃ g : Fin (N + Fintype.card n) → ℝ,
      stateData x _ *ᵥ g = x₀ ∧ hankel u L _ *ᵥ g = ū := sorry

/-- Zero-padded input sequence from a window. -/
def padInput {L : ℕ} (ū : Fin L × m → ℝ) : ℕ → m → ℝ :=
  fun k a => if h : k < L then ū (⟨k, h⟩, a) else 0

def IsIOWindow (A : Matrix n n ℝ) (B : Matrix n m ℝ) (C : Matrix p n ℝ) (D : Matrix p m ℝ)

matrix is exactly the set of length-`L` I/O windows. -/

### 3.4 Hardest step, trick, estimate, risk

* **Hardest step.** The η-peeling in the classical proof: "let s* be the largest index with α_{s*} ≠ 0, then read off η from the top block down".
* **Trick (Cayley–Hamilton-free, spectral-free).** ctrl's own `reach_eq_reach_finrank` supplies a **monic** relation for `(Aᵀ)ⁿξ`, so there is no "largest nonzero coefficient". Every coefficient (η and the `Bᵀ(Aᵀ)^kξ` prefix) goes into one sequence `γ` that satisfies a backward recurrence with a zero tail, so one decreasing induction (K2) kills η and the controllability prefix together. The usual second argument for `ξ` is not needed.
* **Estimate.** ~700 LOC, 7–10 days. **Risk: medium.** It is `Fin`/ℕ index friction in K3, so keep everything ℕ-indexed internally and convert to `Fin L × m` only in the public statements. The `toLin'` bridge to `Controllable` is about 60 LOC of plumbing.
* **Column-count convention.** Stating PE over `N` columns of depth `L+n` and concluding over `N+n` columns of depth `L` avoids natural-number subtraction. The data length is implicitly `T = N + L + n − 1`, which matches the classical `T ≥ (m+1)(L+n) − 1` once PE holds. Numerically checked in 215/215 random controllable+PE cases (Appendix B).

**4a: `cquad_le_zero_of_quad`.** Write `ζ = a + i b` with `a, b` real. For symmetric real `N`, `Re(ζᴴNζ) = quad N a + quad N b`; the cross terms cancel by symmetry. Mathlib: `Complex.mul_conj` (Basic/Complex/Basic.lean:585), `Complex.normSq` (:508), `Matrix.map` (LinearAlgebra/Matrix/Defs.lean:115), `Matrix.conjTranspose` (LinearAlgebra/Matrix/ConjTranspose.lean:43). No `Matrix.PosSemidef.map_ofReal` exists (grep: MISSING), so this ~40 LOC lemma is new.

**4a: soundness.** With `ξ = (x, u)`, `zx = Ax + Bu` and `|z| = 1`: `ξᴴ(M + Φ(P))ξ = ξᴴMξ + |z|²xᴴPx − xᴴPx = ξᴴMξ`. **4a: `brl_certificate_imp_kyp`.** `quad (M_BRL + Φ(P)) (x, w) = ‖Cx + Dw‖² − γ²‖w‖² + quad P (Ax + Bw) − quad P x`, which equals `quad (R∞(P) − P) x − quad M_γ(P) (w − K_w x) ≤ 0` by `hinf_stage_completion_of_squares`. This is direct reuse with no Schur complement. About 60 LOC.

**H1.** For `N₀` in the cone, `quad N₀ ξ ≤ −c‖ξ‖²` (ctrl `exists_quad_lower` applied to `−N₀`), and `|quad (N−N₀) ξ| ≤ (Σ|ΔN_ij|)‖ξ‖²_∞·card`. That gives an open ball. About 60 LOC (no Mathlib `isOpen_posDef`; grep MISSING).

### 4.4 Hardest step, trick, estimate, risk

* **Hardest step.** H7 (unitary diagonalization), followed by the functional-analytic plumbing in H2–H3 (Hahn–Banach on `Matrix` with Pi-topology instances).
* **Tricks.** (a) The kernel-form FDI (`z x = Ax + Bu`) removes `(zI−A)⁻¹` and the `det ≠ 0` side condition from every direction except the transfer-form corollary. (b) Rantzer's duality route avoids Parseval and spectral factorization entirely. (`tsum_sq_fourierCoeff`, Analysis/Fourier/AddCircle.lean:453, exists if a time-domain route is ever preferred.) (c) The soundness direction and the BRL-is-KYP bridge need only completion of squares.
* **No complete spectral-free trick is known for H7.** The induction route (ii) is the least spectral, needing only one eigenvector from algebraic closure.
* **Estimate.** 4a: ~350 LOC, 3–4 days, P = 0.85. Full strict converse: +700–900 LOC, +12–18 days. Non-strict: +1–2 weeks. **P(full KYP in 2 weeks) ≈ 0.2. Risk: high** for the converse.

### 4.5 Prior formalizations

An extended web search found no KYP formalization in Lean, Coq or Isabelle. The only Lean repository that mentions KYP is <https://github.com/AEjonanonymous/Improving-on-Popov>. I cloned it at commit `8e9182c` (2026-09-24): 188 lines, and **it does not prove KYP**. Its headline `n_dimensional_popov_absolute_stability` assumes that the storage function tends to zero (`h_decay`) and a state bound (`h_state_bound`) as hypotheses. The frequency-domain conditions are evaluated only at `w = 0`, and `comparator/Challenge.lean` contains six `sorry`s. MATH-07 would therefore be the first real mechanized KYP. 4a alone would already be the first mechanized "LMI certificate ⇒ frequency-domain bound".
