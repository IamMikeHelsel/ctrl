## Problem and known solution
Let n = p²+p+1. Suppose a family of blocks on [n] (each block has ≥ 2 points) contains every pair of points in exactly one block, and has t > n blocks. Then t ≥ n+p. This is Theorem 2 of Erdős–Fowler–Sós–Wilson, "On 2-designs", JCTA 38 (1985) 131–142 (pages 132 and 135–141). The theorem holds for every p ≥ 2; the prime-power hypothesis is not needed. The paper gives two proofs:
- **Algebraic proof (about 3 pages):** Lemmas 1–4 show that every line has at most p+1 points, every point has degree at least p+1, and some point has degree exactly p+1. The argument then uses the orthogonal projection onto the complement of the row space of the incidence matrix, which has rank b−v, together with a positivity argument on a principal submatrix.
- **Combinatorial proof (about 4 pages):** this derives Theorem 2 from Theorem 4.

The lower bound t ≥ n is the de Bruijn–Erdős theorem (1948).

## What exactly must be proved in Lean
The target is the formal-conjectures statement: `∀ p, IsPrimePow p → ∀ H : Finset (Finset (Fin (p^2+p+1))), H.IsPairwiseBalancedDesign → p^2+p+1 < H.card → p^2+p+1+p ≤ H.card`.
- `IsPairwiseBalancedDesign` (in `FormalConjecturesForMathlib/Combinatorics/Hypergraph/Finite.lean`) means every block has ≥ 2 points and every 2-set lies in a unique block. A block equal to the whole ground set is allowed, but then t = 1, so the hypothesis t > n rules that case out.
- The plby proof uses an indexed family `block : Fin b → Finset _` with its own `PairwiseBalanced` predicate. Turning it into a proof of the formal-conjectures statement needs a short bridge (index a Finset of Finsets by `Fin H.card`, which is injective). Submission #4946 claimed to have built such a "DefEq contract bridge".

## Mathlib readiness (exists / missing)
- **Exists:** Finset double counting, `Matrix.rank` and rank inequalities, positive-semidefinite and orthogonal-projection machinery, `IsPrimePow.two_le`.
- **Missing:** linear spaces and designs, the de Bruijn–Erdős and Stanton–Kalbfleisch bounds, and incidence-matrix theory. Mathlib has no design theory. The plby file builds all of this from scratch, including a `stanton_kalbfleisch` lemma, rank bounds for diagonal plus rank-one matrices, and a projection-rank obstruction.

## Proof plan
This is moot because a complete proof already exists. For reference, the plby proof follows the algebraic route in this order:
1. Show `block_card_le_order_add_one` (no line has more than p+1 points unless t ≥ n+p).
2. Show `degree_ge_order_add_one` (every point has degree ≥ p+1).
3. Show `exists_degree_eq_order_add_one` (some point has degree exactly p+1).
4. Use `exists_minimal_degree_block` (via the projection-rank argument) to find a line whose points all have degree p+1.
5. Apply `number_of_blocks_eq_points_of_minimal_block` to conclude b = v, a contradiction.

No finite computation is involved, so neither `decide` nor `native_decide` is needed. Redoing the proof independently would take about 1–3 days with the plby file as a guide.
