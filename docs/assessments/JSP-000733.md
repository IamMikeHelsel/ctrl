## Problem and known solution
erdosproblems.com/882: largest A ⊆ {1..n} whose nonempty subset sums form a primitive set (no two distinct sums divide each other). ELRSS99 shows |A| > log₂ n − 1 via A = {2^m − 2^i : 0 ≤ i < m}. Because the sums are pairwise distinct, the Erdős–Moser-type distinct-subset-sums bound gives |A| ≤ log₂ n + ½ log₂ log n + O(1). The pigeonhole bound gives |A| ≤ log₂ n + log₂ |A| + O(1), i.e. log₂ n + O(log log n). Whether |A| ≤ log₂ n + O(1) holds is still open. JSP catalog says "Solved", "Lean proof: No", and "Eligible to claim: No".

## What exactly must be proved in Lean
For the solved content, define maximumSize n and prove that log₂ n − 1 < maximumSize n, using the construction. Optionally, also prove the O(log log n) upper bound by pigeonhole on 2^|A| distinct sums ≤ |A|·n. The plby file does the lower bound in 567 lines, with no sorry, no axiom and no native_decide.

## Mathlib readiness (exists / missing)
Exists: `Nat.bitIndices` (Mathlib/Data/Nat/BitIndices.lean), `Finset.card_powerset`, card/injection lemmas, `Real.logb`. Missing: nothing substantive. The binary-weight and 2-adic arguments are elementary, as plby's 567-line file shows.

## Proof plan
(Moot.) Lower bound: show that subset sums of {2^m − 2^i} are k·2^m − (distinct binary numbers). Then prove divisibility is impossible using binary weight and 2-adic valuation, and pick m = ⌊log₂ n⌋ + 1 or similar. Upper bound: injectivity of S ↦ ΣS into [1, |A|n], then 2^|A| − 1 ≤ |A|n. Both are effort S/M, and neither needs a finite computation.
