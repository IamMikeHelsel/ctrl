## Problem and known solution
erdosproblems.com/1205 [Er80, p.108]: F(x) is the largest k such that one can choose a_n mod n for every n ≤ x so that each m ≤ x satisfies at least k of the congruences. Estimate F(x). Erdős called F(x) → ∞ a "simple exercise". The site gives a short argument (Bloom) proving F(x) ~ log x:
- Upper bound: pigeonhole/averaging, F(x) ≤ Σ_{n≤x} 1/n = log x + O(1).
- Lower bound: random a_n for n ≤ x/2, then a Chernoff bound so all but O(x/log²x) of the m are covered ≥ log x − O(√(log x log log x)) times; fix the remaining m greedily using moduli in (x/2, x].
The JSP record (status Solved, publication Er80) only says "estimate F(x)". The natural complete answer is F(x) ~ log x, and that is what the existing formalizations prove.

## What exactly must be proved in Lean
`(fun x : ℕ ↦ (F x : ℝ)) ~[atTop] (fun x ↦ Real.log x)`, with F defined via `Nat.findGreatest` over assignments `(i : Fin x) → Fin (i+1)`. Proving only F → ∞ would probably not count as a full answer to "estimate F(x)".

(2) Prove the lower bound with a counting/exponential-moment argument over all assignments, then the greedy fix-up. No finite computation is needed, so `native_decide` is irrelevant.
