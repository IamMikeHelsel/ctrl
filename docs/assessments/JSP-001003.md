## Problem and known solution
Erdős [Er80, p.104]: if ℕ is 2-coloured, must there be an infinite A = {a₁ < a₂ < …} such that every expression Σ_{j≤k} ∏_{i∈S_j} a_i (disjoint nonempty S_j, excluding the trivial single a_i) is monochromatic? The singleton-blocks case is Hindman's theorem [Hi74]. Answer: NO — Smith [Sm95, JCTA 72 (1995) 77–94] constructs a 2-colouring separating finite products FP(x) from ordered sums of two products. Pairing consecutive terms (a_{2i}a_{2i+1}) turns every finite product into a nontrivial expression, so a monochromatic A would contradict Smith.

JSP catalog: status Solved, Lean proof "No", **Eligible to claim: No**.

## What exactly must be proved in Lean
¬ ∀ c : ℕ → Fin 2, ∃ a strictly increasing, positive, ∃ colour, ∀ admissible nontrivial block families, c(Σ_S ∏_{i∈S} a i) = colour. The hard core is Smith's separation theorem (∃ B ⊆ ℕ+ with no FP-set inside B's complement and no SP2-set inside B), which requires ultrafilter / Stone–Čech arguments on ℕ+ under both + and ×.
