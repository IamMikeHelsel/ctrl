## Problem and known solution
Erdős [Er80, p.92], a question of Spencer: can ℕ be 2-coloured so that every monochromatic k-term AP {a, a+d, …, a+(k−1)d} has k ≪_ε a^ε for every ε > 0? Spencer had shown this with 3 colours and a slowly growing bound (the inverse van der Waerden function). Erdős claimed a 2-colouring with k ≪ a^{1−c}. Zach Hunter answered yes in an erdosproblems.com forum comment. There is no separate paper; the JSP record says "No separate result paper is identified."

The screener called this a "short comment". The proof is not short once formalized. plby's Leanization is about 6,900 lines across ~50 files. The informal proof is in `tex/984.tex` in that repo. It uses a random/structured colouring built from torus rotations, Haar measure, Fourier kernels on `AddCircle`, orbit-hitting estimates, character sums, a matrix-rank argument and an "off-diagonal van der Waerden" style reduction (`erdos984_of_offDiagonal hunterEventualOffDiagonalData`).

## What exactly must be proved in Lean
```lean
∃ color : ℕ → Bool, ∀ ε : ℝ, 0 < ε → ∃ A : ℝ, 0 < A ∧ ∀ a d k : ℕ,
  0 < a → 0 < d → IsMonochromaticAP color a d k → (k : ℝ) ≤ A * (a : ℝ) ^ ε
```
The formal-conjectures version is equivalent: `ℕ → Fin 2`, `C > 0`, and `d ≥ 1` built into `IsMonochromaticAP`.

## Mathlib readiness (exists / missing)
- Exists: `Analysis/Fourier/AddCircle`, `AddCircleMulti`, Haar uniqueness, product measures and integrals, `ToIntervalMod`, pigeonhole, `Matrix.rank`, central binomials, and periodic interval integrals. These are exactly the imports plby uses.
- Missing: everything problem-specific (kernels, orbit hitting, typical-parameter selection, the assembly). This is the ~6.9k lines plby built. No van der Waerden or colouring-AP machinery in Mathlib is needed beyond basics.

## Proof plan
Not pursued. Re-doing the proof would mean reproducing plby's pipeline: Basic/Blocks, then the off-diagonal reduction (Assembly), then Hunter's construction (torus rotation colouring, Fourier/Haar estimates, probabilistic selection of parameters as a positive-measure argument), then Eventual and the final theorem. No finite computation is involved, so `decide`/`native_decide` is irrelevant. Our effort would be L (1–2 weeks) even with plby's tex as a guide, and the result would have no priority.
