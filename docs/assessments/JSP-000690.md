## Problem and known solution
Erdős–Lovász [Er74d, p.282] asked whether there is a 3-critical 3-uniform hypergraph with every vertex of degree ≥ 7. Li, arXiv:2512.24850 (2025), settles both readings:
- **Transversal reading** (τ(H)=3 and τ(H−e)≤2 for every edge e): no such hypergraph exists. For each edge e, pick a 2-set B_e that hits H−e. Then B_e is disjoint from e, and B_e meets every other edge f. Bollobás's set-pairs inequality then gives |E| ≤ C(5,3) = 10. With all degrees ≥ 7 this forces 7n ≤ 30, so n ≤ 4. But on at most 4 vertices any 2-set is a transversal, a contradiction. The proof is about one page, including a self-contained permutation proof of Bollobás's inequality.
- **Chromatic reading**: Li gives an explicit 9-vertex, 22-edge 3-graph with minimum degree 7. It is not 2-colourable, but becomes 2-colourable after deleting any edge or any vertex. The witness colourings are in the paper's appendices, and the proof is a finite check.

## What exactly must be proved in Lean
- parts.i: ¬∃ n H, H is 3-uniform, has a transversal of size ≤3, has no transversal of size ≤2, every H.erase e has a transversal of size ≤2, and every vertex of `Fin n` has degree ≥7. The definitions are in `FormalConjecturesForMathlib/Combinatorics/Hypergraph/Finite.lean`; `HasFiniteTransversal F k := ∃ S, S.card ≤ k ∧ ∀ e ∈ F, ∃ v ∈ S, v ∈ e`.
- parts.ii: exhibit n=9 and Li's H. Then prove uniformity, `HasHypergraphChromaticNumber 3`, colourability after each edge and each vertex deletion, and degree ≥7. `HasHypergraphChromaticNumber 3` means 3-colourable and not j-colourable for j=0,1,2. The colourings are weak (no monochromatic edge).

## Mathlib readiness (exists / missing)
- Exists: Finset combinatorics, `Finset.sum_card_inter`/double counting, `Combinatorics/SetFamily/LYM.lean` (LYM for antichains), and `decide` over `Fin 9`.
- Missing: Bollobás's set-pairs inequality. It is not in Mathlib, but only the uniform special case (|A|=3, |B|=2) is needed, via the permutation-counting proof or the inductive proof. Alternatively, a more ad hoc argument could avoid it.
- The hypergraph definitions already exist in the formal-conjectures util library.

## Proof plan
1. parts.ii: write the explicit edge list. Give an explicit 3-colouring, the 22 edge-deletion and 9 vertex-deletion 2-colourings (Li's Appendix B), and check them with `decide`. For non-2-colourability, reduce `∀ c : Fin 9 → Fin 2` to a Bool check over the 512 tuples, then use kernel `decide` or a reflective `List.all`. This is cheap and needs no `native_decide`. j=0 and j=1 are trivial.
2. parts.i: (a) build the set pairs (e, B_e) with |B_e|=2 from criticality; (b) prove Bollobás's inequality for this case to get |H| ≤ 10; (c) use double counting to get 7n ≤ 3|H| ≤ 30, so n ≤ 4; (d) show every 3-subset of a set of size ≤ 4 meets a fixed 2-set, contradicting ¬τ≤2. Expected size is roughly 150–300 lines.
3. Overall this is S–M effort. The existing plby file already does all of it.
