# Other paid / prize-bearing sources for formal math (beyond JSP, conjectures.io, Palomar, formal-conjectures, SAIR, AI for Math Fund core round, erdosproblems)

Researched 2026-10-17 using web search and fetches of the organisers' own pages. "Value per effort" is a judgement call: expected cash (taking payout likelihood into account) divided by the work needed to get a first payment. ## Notes on the top entries

1. **Mercor Lean contract.** This is the only source found with guaranteed hourly pay at a meaningful rate for pure Lean/Mathlib work. It is labour, not a prize, but nothing else beats its value per effort. The commitment is ≥20 h/wk.
2. **Yukon + matrices.fast.** The weekly $10K is the most liquid prize stream in this space. The raffle half is weighted by points, so even small verified improvements buy tickets. matrices.fast is the KKT ordering problem inside MPC/IPM solvers, which is directly in our wheelhouse. Watch the details: the score is relative to AMD, pure Rust only, and evaluation uses a hidden corpus. Check per-challenge terms for country restrictions before investing time.
3. **RP seed grants.** These are rolling, decide within about 4 weeks, and pay up to $100K. A pitch like "verified estimation & control in Lean" (a matrix Kalman filter, Riccati/LQR, ISS, built on LeanForControl, aligned with TorchLean's verified-ML direction) would be differentiated. RP funded "stochastic algorithms in Lean" and TorchLean in the 2026 core round, which signals appetite.
4. **Conjectures.io float kernels.** This pays for Lean program-equivalence proofs plus speed, not open problems, so it is far more tractable. Champions rotate, so payouts are temporary while you hold a top-3 slot.
5. **better.codes.** It pays twice: Yukon points plus a possible EF award. Progress has slowed to 0.01-bit increments, and fresh ideas are needed to make an attack-bound or lower-bound jump.
6. **Rust std verification.** These are fixed USD bounties of $10K–$25K with clear success criteria. They are not Lean, but the skills transfer. Each challenge is multi-week.
7. **Epoch Open Problems.** This pays mathematicians to *pose* problems, not solve them. It is worth it only if we have a real open problem with a checkable certificate, e.g. an extremal configuration in multi-view geometry or an estimator bound.
8. **Yukon side challenges.** sig.golf, Heesch and EC Rank are extra ways to earn Yukon points.

## Things that changed recently (relevant to strategy)

- AIMO closed on 2026-09-16. XTX moved money to Lean FRO ($10M), the Mathlib Initiative ($10M) and SAIR competitions. Expect more paid Mathlib Initiative contractor slots, not more olympiad prizes.
- The SAIR Lean Kernel Challenge Stage 1 (deadline 2026-11-20) states **no prize money**, and Andrews–Curtis is recognition only (both SAIR, listed for completeness).
- Verified-zkEVM grants are closed, and no Certora FV contest has run in 2026.
