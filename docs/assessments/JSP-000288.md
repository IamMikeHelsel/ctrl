## Problem and known solution
Erdős–Graham [ErGr80, p. 57] considered a sequence A of positive integers with two properties:
- removing any finite set of terms leaves it complete, where "complete" means every sufficiently large integer is a sum of distinct terms;
- removing any infinite set of terms leaves it not complete.

They asked: if also a_{n+1}/a_n ≥ 1+ε for all n, must a_{n+1}/a_n → φ = (1+√5)/2? Graham [Gr64d] showed that a_n = F_n − (−1)^n has both properties.

The answer is no. GPT Pro, prompted by Liam Price, built a counterexample in June 2026. It takes Graham's inhomogeneous Fibonacci recurrence a_{n+2} = a_{n+1} + a_n ± 1 and adds sparse perturbations b_{N_j} = ⌊a_{N_j}/4⌋ at rapidly increasing indices N_j. In the resulting sequence:
- every ratio a_{n+1}/a_n is at least 6/5;
- a_{N_j}/a_{N_j−1} → φ, while a_{N_j+1}/a_{N_j} → φ + 1/4, so the ratios do not converge.

The proof write-up is on Overleaf. Nat Sothanaphan screened it and found only one typo (in Lemma 3, "j ≥ 3" should be "j ≥ 4").

Side note: KitaKen1 and Nat Sothanaphan proved, also in Lean, an alternative "limit exists" reading: if the limit L > 1 exists, then L = φ. That repo is KitaKen1/erdos346-ratio-limit-lean, and it is also in LeanPool.

## What exactly must be proved in Lean
`erdos_346 : ¬ ∀ {A : ℕ → ℕ}, IsLacunary A → IsAddStronglyCompleteNatSeq A → (∀ B ⊆ range A, B.Infinite → ¬ IsAddComplete (range A \ B)) → Tendsto (A (n+1)/A n) atTop (𝓝 φ)`.

This needs one explicit sequence A with four properties:
1. It is lacunary (ratio at least 6/5 > 1).
2. Every tail `fun m => A (n+m)` is complete. This is the hard infinite-family argument.
3. Removing any infinite set of terms makes it incomplete. The file's `not_isAddComplete_range_diff_of_sum_range_le` handles this if the partial-sum bound holds for the perturbed sequence.
4. Its ratios do not converge to φ.

Note that the file's `f` (Graham's sequence) is not a counterexample, because its ratios do tend to φ. The perturbed construction is required. Price's existing Lean statement deletes by index sets (`subsetSums a Dᶜ`), so adapting it to the formal-conjectures definitions (deletion by range sets, tails for strong completeness) is a short bridge because the sequence is strictly increasing.

## Mathlib readiness (exists / missing)
- Exists: `Nat.fib` and its lemmas, `goldenRatio` (Mathlib/NumberTheory/Real/GoldenRatio.lean), Fibonacci ratio limits (Mathlib/Analysis/SpecificLimits/Fibonacci.lean), and `tendsto_nhds_unique`.
- Exists in formal-conjectures: `IsAddComplete`, `IsAddStronglyCompleteNatSeq`, `subsetSums`, and the infinite-deletion criterion `not_isAddComplete_range_diff_of_sum_range_le`.
- Missing from Mathlib, but already written in Price's public file: the interval-extension or "permanent interval certificate" lemma, Graham's bounded-gap descent showing every tail is complete, the staged construction of the perturbation indices, and the ratio asymptotics.

## Proof plan
(Moot because of priority.) Take the public `Erdos346.erdos346` proof, which uses Mathlib only, and rebuild it against the formal-conjectures definitions. Then derive `erdos_346`:
- lacunarity from the 6/5 lower bound;
- `IsAddStronglyCompleteNatSeq` from finite-deletion completeness, using D = {0,…,n−1};
- range-set deletion converted to index-set deletion through StrictMono injectivity;
- non-convergence from `final_quotients_not_convergent`.

This needs no finite computation and no `native_decide`. As a port it is about 1–3 days of work; done from scratch it would be L.

## Risks and open questions
- A complete public proof has existed since 19 Jun 2026, and a git commit since 26 Aug 2026 at the latest. At least eight PRs or claims for this record have already been filed. Our team would almost certainly not be first. Porting someone else's proof would add no value and risks looking like plagiarism.
- The JSP review on 2026-09-11 still lists the record as "unformalized" with "Eligible to claim: No". The record may therefore be disputed or pending reconciliation of the existing claims, but that does not help us.
- There is also interpretive ambiguity, since the problem can be read as assuming the limit exists. The "limit exists" reading is already in Lean too (KitaKen1), and closing it fully may also need Burr–Erdős for the case L < φ.
