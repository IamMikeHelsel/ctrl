## Problem and known solution
Burr/Erdős conjectured R(T) = 4k−1 for every tree T with bipartition classes of size k and 2k (4k−1 is the trivial lower bound from EFRS82). Norin–Sun–Zhao [NSZ16] disproved it: for the double star S(k−1, 2k−1) (stars on k and 2k vertices with centres joined), R(T) ≥ (4.2−o(1))k. The construction is a clique blow-up of a line graph of a complete graph; any single explicit k with a 2-colouring of K_{4k−1} avoiding a monochromatic double star suffices.

## What exactly must be proved in Lean
`¬ ∀ k ≥ 2, ∀ T : SimpleGraph (Fin k ⊕ Fin (2k)), T.IsTree → (bipartite in the given sides) → diagonalGraphRamsey T = 4k−1`, with `graphRamsey G H = sInf {n | ∀ C : SimpleGraph (Fin n), G ⊑ C ∨ H ⊑ Cᶜ}`. Since sInf S = 4k−1 forces 4k−1 ∈ S, it suffices to exhibit one k, a double-star tree T on `Fin k ⊕ Fin (2k)`, and one graph C on `Fin (4k−1)` with T ⋢ C and T ⋢ Cᶜ. No upper bound needed. My quick computer search found no *circulant* witness for k ≤ 6 (regular colourings fail); known Lean witnesses use k = 16 (63 vertices, plby) and a 35-vertex one (k = 9, PR #867).

## Mathlib readiness (exists / missing)
- Exists: `SimpleGraph.IsContained` (⊑), `IsTree`, complement, `Nat.sInf_mem`, Finset card machinery, `decide`.
- In formal-conjectures util: `graphRamsey`, `diagonalGraphRamsey`.
- Missing (small): criterion "double star S(a,b) ⊑ G iff ∃ edge uv with |N(u)\{v}| ≥ a, |N(v)\{u}| ≥ b, |N(u)∪N(v)\{u,v}| ≥ a+b" (only the ⇒ direction is needed), plus degree/neighbourhood computations for the explicit witness graph.

## Proof plan
1. Define T = S(k−1, 2k−1) on `Fin k ⊕ Fin (2k)`; prove IsTree and bipartition (decide/explicit path).
2. Define the NSZ witness (e.g. 3-fold clique blow-up of L(K₇), 63 vertices, k = 16) on `Fin 63`.
3. From an embedding T ⊑ C, extract the image edge of the centres and the injective leaf images, giving the neighbourhood-size inequalities.
4. Show by structural counting (or kernel `decide` on per-vertex neighbourhood sizes) that every edge in C and in Cᶜ violates them.
5. Conclude 4k−1 ∉ S, hence sInf ≠ 4k−1. plby's 389-line proof follows exactly this plan using plain `decide`.
