## Problem and known solution
Erdős (1974) asked: for r ≥ 3 and k large in terms of r, does every r-uniform hypergraph with chromatic number k have at least C((r−1)(k−1)+1, r) edges, with equality only for the complete r-graph on (r−1)(k−1)+1 vertices? Alon (Graphs Combin. 1985) disproved this with a Turán-type construction that gives fewer edges for some r ≥ 4. The case r = 3 is still open. Later papers give asymptotic bounds: Akolzin–Shabanov (2016) and Cherkashin–Petrov (2020). JSP lists the problem as Solved, Lean proof No, Eligible to claim No.

## What exactly must be proved in Lean
The formal-conjectures statement is a negation: ¬ ∀ r ≥ 3, ∀ᶠ k in atTop, ∀ n (H : Finset (Finset (Fin n))), H is r-uniform with chromatic number k → (binomial lower bound ∧ equality forces a complete r-graph). It is enough to give one r (firesh uses r = 4, via Giraud's 1990 construction) and infinitely many k with an r-uniform hypergraph of chromatic number exactly k and fewer than C(3(k−1)+1, 4) edges. Exact chromatic number is the hard part: the lower bound needs a no-proper-(k−1)-colouring argument that holds for every k.

## Mathlib readiness (exists / missing)
- Exists: `Finset.powersetCard`, `Nat.choose` and its identities, and Finset counting and pigeonhole lemmas. formal-conjectures supplies `Finset.IsUniform` and `HasHypergraphChromaticNumber`.
- Missing: there is no hypergraph colouring theory in Mathlib. That means building the construction itself, the proof that it is not (k−1)-colourable (a pigeonhole and Turán-type argument), an explicit k-colouring, and the edge count compared with the binomial. Both existing proofs build all of this from scratch, in under about 1000 lines.

## Proof plan
(Not pursued, given the priority situation.) Fix r = 4. For each k, define a Giraud/Alon-type 4-graph on about 3(k−1)+1 vertices that omits some 4-sets from the complete graph while still forcing k colours. Prove it cannot be properly (k−1)-coloured, give an explicit proper k-colouring, and show its edge count is strictly below C(3k−2, 4). Since the construction is parametric in k, `decide` cannot be used for the main theorem. native_decide is not allowed anyway.
